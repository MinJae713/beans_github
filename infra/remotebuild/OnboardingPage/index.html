SSAFY A303 · Colosseum

빠르게 붙고, 한 번 더 붙고, 마지막에 살아남는 2D 대전.

Colosseum은 Nidhogg의 압박감과 ROUNDS의 변칙성을 섞은 2인 대전 게임입니다. 라운드가 지날수록 카드 효과가 누적되고, 단순한 에임보다 포지션과 템포 관리가 더 중요해집니다.

Mode 1v1 Online Match

다운로드는 브라우저 기본 다운로드 기능을 사용합니다.

현재 페이지는 정적 HTML 기준입니다. 따라서 다운로드 버튼은 서버 측에서 미리 준비된 downloads/Client.zip 파일을 그대로 제공합니다. 실제 저장 위치는 브라우저 설정에 따라 일반적으로 로컬 PC의 다운로드 폴더로 결정됩니다.

플레이 흐름

게임을 실행하면 먼저 로비에 접속하고, 방을 생성하거나 기존 방에 합류한 뒤 두 플레이어가 준비 상태가 되면 매치가 시작됩니다. 대전 중에는 카드 선택과 방 이동 타이밍이 승부를 크게 좌우합니다.

  • 로비에서 방 생성 또는 방 목록 조회 후 입장
  • 양 플레이어 준비 완료 시 카운트다운 시작
  • 라운드 진행 중 방/포지션 전환과 교전 반복
  • 카드 효과가 누적되며 경기 양상이 점점 달라짐
