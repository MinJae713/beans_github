# 아카이브

이 디렉토리는 현재 기준으로 사용하지 않는 문서를 보관한다.

`90_백로그`는 앞으로 다시 진행할 살아있는 항목이고, `99_아카이브`는 폐기되었거나 대체되었지만 판단 근거로 보존할 가치가 있는 항목이다.

## 보관 대상

| 대상 | 예시 |
|---|---|
| deprecated | 현재 기준에서 밀려난 과거 문서 |
| superseded | 새 문서로 대체된 초안 |
| rejected | 검토했지만 채택하지 않은 방향 |
| historical | 과거 판단 근거로만 필요한 기록 |

## 사용 규칙

- 현재 작업 기준으로 쓰는 문서를 이곳에 두지 않는다.
- 나중에 해야 할 작업은 이곳이 아니라 `90_백로그`에 둔다.
- 아카이브로 이동할 때는 대체 문서나 폐기 이유를 문서 상단에 남긴다.
- 작업자는 이 디렉토리의 문서를 현재 기준으로 해석하지 않는다.
