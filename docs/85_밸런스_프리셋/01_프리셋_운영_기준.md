# 프리셋 운영 규칙

이 문서는 전투 수치 프리셋을 어떻게 만들고 교체하고 기록할지 정의한다.

기준문서는 수치 원칙을 다루고, 실제 수치는 Unity 프로젝트의 프리셋 구현체에서 관리한다.

## 권장 구현 위치

```text
Assets/_LoopDuel/Config/Balance/
- BalanceProfile_v0_1.asset
- BalanceProfile_v0_2.asset
- BalanceProfile_Playtest_A.asset
- BalanceProfile_Tournament.asset
```

위 경로는 권장안이다. 실제 Unity 구조가 달라지면 `50_기술_구조_기준`에서 확정한 경로를 우선한다.

## 프리셋 역할

| 프리셋 유형 | 목적 |
|---|---|
| version preset | 현재 기본 플레이 기준 |
| playtest preset | 특정 가설을 검증하기 위한 테스트 수치 |
| tournament preset | 발표/시연/대회용으로 안정화한 수치 |
| experimental preset | 아직 검증되지 않은 실험 수치 |

## 프리셋에 들어갈 수 있는 값

- 플레이어 체력
- 기본 무기 피해량
- 발사 간격
- 탄속
- 장탄수
- 재장전 시간
- 넉백 계수
- 이동 속도 보정
- 점프/공중 제어 보정
- 카드 효과 수치
- 스킬 쿨타임

## 프리셋 변경 규칙

1. 기준문서에는 수치 값을 직접 고정하지 않는다.
2. 수치 변경은 새 프리셋 또는 명시된 프리셋 버전 변경으로 처리한다.
3. 플레이테스트용 프리셋은 목적을 이름이나 설명에 남긴다.
4. 발표/시연용 프리셋은 실험용 프리셋과 분리한다.
5. 코드에서 특정 수치에 직접 의존하지 않도록 한다.

## 문서에 남길 기록

프리셋 자체의 모든 숫자를 문서에 복사하지 않는다. 대신 아래 정보만 남긴다.

| 항목 | 내용 |
|---|---|
| preset name | 프리셋 이름 |
| purpose | 무엇을 검증하거나 안정화하려는 프리셋인지 |
| owner | 변경 책임자 또는 세션 |
| date | 생성/변경일 |
| linked test | 관련 플레이테스트 또는 smoke 결과 |
| decision | 유지, 폐기, 수정, 승격 중 하나 |

## 금지

- 기준문서에 체력, 피해량, 쿨타임 같은 값을 최종값처럼 박지 않는다.
- 플레이테스트 없이 프리셋을 `Tournament` 또는 기본값으로 승격하지 않는다.
- 구현 코드에 임시 수치를 흩뿌리지 않는다.
- 카드 효과 수치를 카드 설명 문서와 구현 프리셋에 중복 관리하지 않는다.
