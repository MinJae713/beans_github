# 플레이테스트 변경로그

이 문서는 플레이테스트 이후 수치와 프리셋을 왜 바꿨는지 기록하기 위한 자리다.

## 기록 양식

| 항목 | 내용 |
|---|---|
| 날짜 | 테스트 또는 변경 일자 |
| 빌드 | 테스트한 빌드 식별자 |
| 변경 대상 | 바꾼 프리셋 또는 필드 |
| 변경 전 | 이전 후보 |
| 변경 후 | 새 후보 |
| 근거 | 관찰 로그, 플레이어 피드백, 리플레이, 버그 |
| 영향 예상 | TTK, 카드 선택 빈도, 구간 돌파율, 체감 압박 |
| 다음 확인 | 다음 테스트에서 확인할 항목 |

## 운영 규칙

- 수치 변경은 이유 없이 하지 않는다.
- 한 번에 여러 축을 크게 바꿨다면 원인 분석이 어려워진다는 점을 기록한다.
- 기준문서 원칙을 바꿔야 하는 수준의 변경이면 먼저 의사결정 로그에 올린다.
