# 수치프리셋

이 디렉토리는 테스트용 수치 후보를 둔다.

체력, 피해량, 탄속, 장탄수, 카드 등장 가중치, 구간 길이 같은 값은 기준문서 본문에 고정하지 않고 이 계층 또는 Unity 프리셋 구현체에서 관리한다.

## 작성 원칙

- 수치는 확정값이 아니라 테스트 후보로 적는다.
- 수치를 바꿀 때는 변경 이유와 관찰 결과를 함께 남긴다.
- 기준문서의 원칙과 충돌하는 수치는 만들지 않는다.
- 실제 적용값은 Unity `BalanceProfile` 계열 데이터와 일치해야 한다.
