# MVP 전투 수치 프리셋

이 문서는 MVP 전투 수치 후보를 기록하기 위한 자리다.

현재 단계에서는 구체 수치를 확정하지 않는다. 실제 숫자는 플레이테스트 또는 구현 담당자 합의 후 `BalanceProfile` 계열 데이터와 함께 기록한다.

## 관리 대상

| 항목 | 설명 |
|---|---|
| 체력 | 기본 생존 시간과 TTK에 직접 영향을 주는 값 |
| 피해량 | 기본탄, 탄환 카드, 구조물 피해의 후보 값 |
| 탄속 | 투사체 회피 가능성과 명중 난이도에 영향을 주는 값 |
| 장탄수 | 발사 리듬과 재장전 빈도를 결정하는 값 |
| 재장전 | 압박 유지와 빈틈 형성에 영향을 주는 값 |
| 넉백 | 위치 기반 킬각과 경계 압박에 영향을 주는 값 |

## 작성 규칙

- 수치는 확정값이 아니라 테스트 후보로 적는다.
- 수치 변경 이유는 `85_밸런스_프리셋/30_변경로그/01_플레이테스트_변경로그.md`에 남긴다.
- 기준문서의 TTK 철학과 카드 선택 빈도 기준을 깨는 값은 사용하지 않는다.
- 코드 상수로만 남기지 않고 `BalanceProfile` 계열 데이터와 연결한다.

## 작성 대기

첫 플레이어블 slice에서 기본탄, 피격, 사망, 리스폰, 카드 선택 흐름이 연결된 뒤 작성한다.
