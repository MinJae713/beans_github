# 프로젝트 비전

> 상태: accepted_candidate. 이 문서는 게임 정체성, 만들지 않을 것, 핵심 재미 방향에 한해 임시 구현 기준으로 사용한다. 문서 상태와 binding 범위는 `05_문서관리_규칙/08_문서_상태_인덱스.md`를 우선한다.

## 한 문장 정의

Colloseum은 `Nidhogg`식 전장 돌파와 `ROUNDS`식 패자 성장 카드를 결합한 2D 실시간 대전 게임이다.

MVP는 1v1 대전을 전제로 한다. 팀전 2v2는 상태머신, 카드 지급, 리스폰, 구간 돌파 규칙을 다시 정의해야 하므로 MVP 범위에서 제외하고 백로그로 관리한다.

## 핵심 재미

| 축 | 설명 |
|---|---|
| 위치 싸움 | 상대를 죽이는 것뿐 아니라 구간을 밀고 넘어가는 재미 |
| 역전 성장 | 구간 돌파를 당한 플레이어가 카드를 받아 다음 전투 양상이 바뀌는 재미 |
| 짧은 라운드 반복 | 일반 사망 후 재정렬, 구간 돌파 패배 후 카드 선택, 재전투가 이어지는 템포 |
| 물리 반응감 | 2D 물리, 넉백, 피격 피드백으로 몸싸움 감각을 만든다 |

## 플레이어가 체감해야 하는 것

- 한 번의 킬보다 `구간을 밀어붙이는 압박`이 더 중요해야 한다.
- 구간 돌파를 당한 플레이어는 카드 선택으로 다음 교전에서 다른 시도를 할 수 있어야 한다.
- 일반 사망은 카드 선택 없이 재정렬과 재교전으로 이어진다.
- 총알, 이동, 점프, 넉백은 가볍고 읽기 쉬워야 한다.
- 전투가 너무 빨리 끝나 카드 선택 시간이 플레이타임 대부분을 차지하면 안 된다.

## 만들지 않을 것

| 제외 대상 | 이유 |
|---|---|
| 복잡한 RPG 성장 | 라운드 단위 대전 템포를 흐린다 |
| 장시간 파밍/경제 | 실시간 1v1 전투 집중도를 낮춘다 |
| 정밀 군사 슈터 | 위치 압박과 카드 변주가 아니라 에임 실력만 남는다 |
| 완전 랜덤 난전 | 카드 선택이 전략이 아니라 운으로 느껴진다 |
| 네트워크 래그돌 동기화 | 비용과 디싱크 위험이 커서 사용하지 않는다 |
| MVP 팀전 2v2 | 1v1 상태머신 안정화 전에는 카드/돌파/리스폰 규칙이 과도하게 복잡해짐 |
| 1차 WebGL 공식 지원 | Server Mode와 WebSocket 제약 검증 전에는 시연 리스크가 큼 |

## 우선순위

1. 게임 품질: 조작감, 전투 템포, 카메라, 피격 피드백.
2. 에셋/비주얼: ROUNDS식 미니멀 2D 톤, 플랫 셰이딩 감각, 읽기 쉬운 실루엣.
3. 구현 전달 효율: 기준문서, 작업 브리핑, smoke test로 사람과 AI의 결과물을 같은 기준으로 검증한다.

## 미결정

- 최종 아트 톤과 캐릭터 실루엣 세부안.
- 카드 UI의 최종 인터랙션 방식.
- 온라인 매칭, 관전, 랭킹의 2차 릴리스 포함 범위.
