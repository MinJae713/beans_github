## 매트릭스 사용 원칙

| 상황 | 처리 |
|---|---|
| 작업 유형이 여러 카테고리 걸침 | 모든 해당 행의 "필수" 문서 합집합을 로드 |
| 시간·컨텍스트 예산 부족 | "필수"만 로드, "권장"은 필요 시 참조 |
| 매트릭스에 없는 작업 유형 | [README](../README.md) 공통 선행 4개만 읽고, 불확실하면 사용자에게 문의 |
| `accepted` 문서와 `candidate` 문서 충돌 | `accepted` 우선 ([README](../README.md) SOT 선언) |

## 미결정

- 매트릭스에 빠진 작업 유형 (빌드 · 배포 · CI/CD · 사용자 데이터 · 운영 텔레메트리) — W2~W3 중 확장 예정
