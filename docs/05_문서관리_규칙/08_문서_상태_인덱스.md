# 문서 상태 인덱스

이 문서는 팀 공유 기준문서 묶음 안에서 어떤 문서를 현재 구현 기준으로 볼 수 있는지 한 곳에서 확인하기 위한 상태 인덱스다.

README와 이 문서를 먼저 읽지 않은 상태에서 개별 문서만 보고 구현을 시작하지 않는다.

## 상태 읽기

> 상태 정의와 전이 규칙의 정본은 [01_문서_상태와_변경_규칙.md](01_문서_상태와_변경_규칙.md) 참조. 본 문서는 **상태별 파일 인덱스** 기능만 담당한다.

### 등재되지 않은 문서 처리

- "현재 binding set"과 "accepted_candidate set"에 개별 등재된 문서는 해당 행의 binding 범위를 따른다.
- 도메인 glob(`20_전투_밸런스_기준/**`, `90_백로그/**` 등)에 속하지만 개별 등재되지 않은 문서는 해당 glob 상태를 따른다.
- 본문 상단 `> 상태: ...` 선언이 glob과 다르면 **본문 선언이 우선**한다. 예: `90_백로그/**`는 기본 backlog지만 `90_백로그/07`, `08`이 본문에 `reference`로 선언한 경우 reference 취급.
- 개별 등재도 없고 본문 상태 선언도 없는 문서는 구현 기준으로 사용할 수 없으며, 필요 시 작업 브리핑에서 임시 승인한다.

## 작업 브리핑에서 해야 할 일

작업 브리핑은 아래를 반드시 적는다.

| 항목 | 기준 |
|---|---|
| accepted 문서 | 충돌 여부를 먼저 확인 |
| accepted_candidate 문서 | 사용한 문서, 임시 가정, 중단 조건을 명시 |
| candidate 문서 | 소유자 확인 또는 한시 승인 없이 구현 기준으로 사용 금지 |
| 미결정 질문 | 관련 QID와 상태를 적고, P0 open/blocked면 중단 |
| Git/Jira | 실제 GitLab 설정과 담당자 지시를 확인 전제로 작성 |
