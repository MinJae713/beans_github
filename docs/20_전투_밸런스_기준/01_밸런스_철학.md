# 밸런스 철학

이 문서는 전투 밸런스의 판단 기준을 정의한다.

구체적인 체력, 피해량, 쿨타임, 탄속, 장탄수, 재장전 시간 같은 수치 값은 이 문서에 고정하지 않는다. 수치는 버전별 `BalanceProfile` 또는 동등한 프리셋 구현체에서 관리한다.

## 핵심 원칙

| 원칙 | 의미 |
|---|---|
| 수치 비고정 | 기준문서는 숫자가 아니라 판단 기준을 다룸 |
| 긴 교전감 | 즉사보다 위치, 압박, 재장전 타이밍이 중요함 |
| 역전 가능성 | 패배 보상은 역전 기회를 주되 확정 승리를 막음 |
| 과성장 방지 | 카드 누적이 전투 선택지를 지우면 안 됨 |
| 교체 가능성 | 수치는 프리셋 단위로 갈아끼울 수 있어야 함 |

## 기준문서에 적어도 되는 것

- 기본 무기는 한 탄창만으로 풀피 대상을 확정 처치하면 안 된다.
- 기본 전투는 순수 화력보다 위치 압박과 자원 소모 판단이 중요해야 한다.
- 패배 보상 카드는 뒤처진 플레이어에게 선택지를 주되, 단일 카드가 즉시 승패를 확정하면 안 된다.
- 카드와 무기는 전장 돌파, 구간 방어, 카메라 압박, 재장전 타이밍과 연결되어야 한다.
- 밸런스 변경은 플레이테스트 목적과 관찰 결과를 함께 남긴다.

## 기준문서에 고정하지 않는 것

- 체력 값
- 피해량 값
- 탄속 값
- 장탄수 값
- 재장전 시간
- 발사 간격
- 쿨타임
- 넉백 계수
- 카드별 정확한 수치

## 수치 변경 판단선

수치 변경은 단순히 강하거나 약하다는 감각만으로 확정하지 않는다. 아래 질문에 답할 수 있어야 한다.

| no | 질문 |
|---|---|
| 1 | 어떤 플레이 양상을 바꾸기 위한 변경인가? |
| 2 | 전장 돌파와 구간 방어 중 무엇에 영향을 주는가? |
| 3 | 초보자와 숙련자에게 다르게 작동하는가? |
| 4 | 카드 누적 이후에도 의미 있는 선택지가 남는가? |
| 5 | 이전 프리셋으로 되돌릴 수 있는가? |

## 구현 연결

Unity 구현에서는 전투 수치를 코드 상수로 박지 않는다. 가능한 한 `ScriptableObject`, JSON, CSV, 또는 동등한 데이터 프리셋으로 분리한다.

기획 문서는 수치의 방향과 금지선을 관리하고, 구현은 프리셋을 읽어 적용하는 구조를 만든다.
