# TTK 판단 프레임

이 문서는 전투 시간이 너무 짧거나 길어질 때 어떤 기준으로 판단할지 정의한다.

정확한 목표 초, 체력, 피해량, 발사 간격, 장탄수, 재장전 시간은 이 문서에 고정하지 않는다. 해당 값은 `BalanceProfile`과 플레이테스트 프리셋에서 관리한다.

## TTK의 역할

TTK는 단순히 "몇 초 만에 죽는가"가 아니라, 카드 선택 시간과 전투 시간의 비율, 위치 싸움의 여지, 역전 가능성을 함께 조절하는 기준이다.

| 판단축 | 의미 |
|---|---|
| 전투 체감 길이 | 플레이어가 위치, 장전, 회피 판단을 할 시간이 있는가 |
| 카드 선택 비율 | 플레이타임 대부분이 선택 UI에 묶이지 않는가 |
| 위치 킬각 | 체력 삭제보다 벽 몰이와 구간 돌파 압박이 살아있는가 |
| 반격 여지 | 한 번 맞아도 조작과 판단으로 회복할 여지가 있는가 |
| 관전 가독성 | 피격과 사망의 원인이 관전자에게 이해되는가 |

## 좋은 TTK의 조건

- 기본 무기 교전에서 첫 피격이 곧바로 사망 확정으로 이어지지 않는다.
- 맞은 플레이어가 최소한 위치 회복, 반격, 회피, 장전 타이밍 흔들기 중 하나를 시도할 수 있다.
- 전투가 길어져도 서로 의미 없는 견제만 반복하지 않는다.
- 카드가 강해져도 전투가 즉사전으로 붕괴하지 않는다.
- 구조물, 고저차, 카메라 압박이 체력 수치만큼 중요하게 작동한다.

## 나쁜 TTK 신호

| 신호 | 해석 |
|---|---|
| 첫 교전 즉사 | 카드 선택 시간이 전투 시간보다 커져 루프가 깨질 위험 |
| 끝없는 견제전 | 돌파/압박 수단이 부족하거나 방어가 과도함 |
| 체력만 보고 도망 | 위치 킬각보다 HP 보존이 지나치게 우선됨 |
| 카드 한 장으로 삭제 | 패배 보상이 역전 기회가 아니라 확정 승리가 됨 |
| 원인 불명 사망 | 피격 신호, 넉백 방향, 구조물 위험 신호가 부족함 |

## 조정 순서

TTK가 문제라고 판단되면 바로 피해량부터 바꾸지 않는다. 아래 순서로 원인을 분리한다.

```text
1. 사망 원인이 체력 삭제인지, 위치 이탈인지, 구조물인지 구분한다.
2. 기본 무기만의 문제인지, 특정 카드/무기 계열의 문제인지 구분한다.
3. 조작 회복 가능성, 점프/대시 소모, 재장전 타이밍을 확인한다.
4. 수치 변경 없이 피드백, 탄도, 발사 리듬, 맵 구조로 해결 가능한지 본다.
5. 그래도 필요할 때만 BalanceProfile 프리셋을 새로 만든다.
```

## 무기 계열별 TTK 기대

| 계열 | TTK 관점의 역할 |
|---|---|
| 결투형 | 기준점. 정면 교전의 평균 체감을 잡는 비교 대상 |
| 돌파형 | 직접 처치보다 밀어내기, 벽 몰이, 구간 돌파 압박을 강화 |
| 제압형 | 짧은 경직과 행동 제한으로 다음 킬각을 만들지만 확정 처치는 금지 |
| 저격형 | 큰 보상을 주되 빗나갔을 때 반격 창구가 명확해야 함 |
| 곡사형 | 엄폐 뒤 압박과 공간 장악을 만들되 무조건 안전한 공격이면 안 됨 |

## 카드 선택 시간과의 관계

- 카드 선택은 전투 결과를 바꾸는 보상 상태이므로 의미 있는 시간이 필요하다.
- 전투가 너무 짧으면 플레이타임 대부분이 선택과 리스폰이 되어 전투 게임의 밀도가 떨어진다.
- 전투가 너무 길면 카드 선택과 역전 구조가 체감되지 않는다.
- 따라서 TTK 조정은 항상 `전투 시간`, `선택 시간`, `리스폰/재정렬 시간`의 비율로 판단한다.

## 구현 연결

- TTK 검증은 단일 수치 비교가 아니라 로그와 플레이테스트 관찰로 판단한다.
- 구현자는 피해량, 탄속, 장탄수, 재장전 시간 같은 값을 코드 상수로 박지 않는다.
- TTK 실험은 `BalanceProfile` 파생 프리셋으로 분리하고 목적을 남긴다.
- 사망 원인, 마지막 피격, 마지막 넉백, 구간 돌파 원인은 로그로 남길 수 있어야 한다.

## 금지

- 기준문서에 목표 초 단위 TTK를 최종값처럼 고정하는 것.
- 기본 무기를 한 번 맞으면 사실상 죽는 구조로 만드는 것.
- 카드 한 장이 반응 불가능한 즉사 루프를 만드는 것.
- TTK 문제를 무조건 체력과 피해량만으로 해결하는 것.
- 플레이테스트 근거 없이 발표/시연 프리셋을 기본값으로 승격하는 것.

## 미결정

- 첫 플레이테스트에서 기록할 TTK 관찰 항목.
- 사망 로그에 어떤 필드를 남길지.
- 저격형 탄환의 실제 승격 시점. 기본탄, 넉백/충격, 반사, 곡사 리허설 이후 판단한다.
