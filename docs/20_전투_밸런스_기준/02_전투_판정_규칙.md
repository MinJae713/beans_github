# 전투 판정 규칙

이 문서는 공격, 투사체, 피격, 넉백, 사망, 구간 돌파 판정의 책임 경계를 정의한다.

피해량, 탄속, 재장전 시간, 쿨타임, 넉백 계수, 경직 시간 같은 수치값은 이 문서에 고정하지 않는다. 해당 값은 `BalanceProfile`과 무기/카드 프리셋에서 관리한다.

## 핵심 원칙

| 원칙 | 의미 |
|---|---|
| 서버 권위 판정 | 피격, 사망, 돌파 결과는 authoritative tick에서 확정 |
| 투사체 중심 전투 | 기본 전투와 MVP 무기는 투사체 기반으로 설계 |
| 위치 킬각 우선 | 체력 삭제보다 위치 압박과 경계 판정이 중요 |
| 연출 분리 | 히트스톱, 카메라, 이펙트는 판정 이후 재생 |
| 수치 프리셋화 | 판정 구조와 수치값을 분리 |

## 판정 소유권

| 항목 | 소유 주체 | 기준 |
|---|---|---|
| 이동 입력 | InputAuthority | 입력 제출만 담당 |
| 이동 결과 | StateAuthority | authoritative tick에서 반영 |
| 발사 입력 | InputAuthority | 발사 의도 제출 |
| 탄 생성 | StateAuthority | 발사 가능 조건 확인 후 생성 |
| 투사체 이동 | StateAuthority | 네트워크 truth 대상 |
| 피격 판정 | StateAuthority | collider/hitbox 결과 확정 |
| 피해/넉백/경직 | StateAuthority | 게임 결과 상태로 반영 |
| VFX/SFX/카메라 | Local Presentation | 확정 결과 또는 예측 결과 표현 |

## 투사체 생명주기

```text
발사 입력
-> 발사 가능 조건 확인
-> 투사체 생성
-> authoritative 이동
-> 충돌 후보 감지
-> 피격/반사/소멸/관통/폭발 중 하나로 해결
-> 결과 상태 반영
-> presentation 피드백 재생
```

투사체가 어떤 생명주기 분기를 가지는지는 무기 계열과 카드 효과가 정한다. 단, 모든 분기는 authoritative 결과를 먼저 확정하고 연출을 따라붙인다.

## 피격 처리

- 피격은 단순 체력 감소가 아니라 위치, 넉백, 경직, 사망 가능성을 함께 만든다.
- 같은 tick에서 여러 피격이 들어오면 authoritative tick 처리 순서에 따라 결과를 하나로 정리한다.
- 피격 후 사망 조건과 구간 돌파 조건이 동시에 발생하면 `라운드 상태머신`의 결과 판정 우선순위를 따른다.
- 피격 판정은 플레이어가 이해 가능한 시각 신호와 연결되어야 한다.

## 넉백과 경직

- 넉백은 구간 돌파, 벽 몰이, 카메라 압박과 연결되는 핵심 전투 결과다.
- 경직은 상대 입력을 완전히 빼앗는 효과이므로 남용하지 않는다.
- 넉백과 경직은 무조건 킬을 보장하는 효과가 아니라 다음 선택지를 강제하는 효과여야 한다.
- 정확한 힘, 시간, 회복 조건은 프리셋에서 관리한다.

## 동시 판정

| 상황 | 처리 기준 |
|---|---|
| 동시 사망 | 상태머신의 결과 판정 규칙으로 해결 |
| 사망과 구간 돌파 동시 | 구간 돌파를 우선 검토. 최종 구간 진입이면 `VictoryRun`, 최종 구간 끝 지점 도달이면 매치 종료로 분리 |
| 투사체와 구조물 동시 충돌 | 무기/구조물 규칙에 따라 하나의 결과로 정규화 |
| 클라이언트 예측과 서버 결과 불일치 | 서버 결과로 보정하고 presentation만 보정 |

동시 판정은 플레이어가 납득하기 어려운 영역이다. 구현자는 결과가 흔들릴 수 있는 지점을 테스트로 고정해야 한다.

## 구조물과 전투 판정

- 구조물은 피격, 반사, 압사, 위험 지형, 이동 발판 중 하나 이상의 명확한 역할을 가져야 한다.
- 구조물이 전투 결과에 영향을 주는 경우 authoritative 상태 또는 이벤트로 처리한다.
- 단순 파티클, 배경 애니메이션, 카메라 연출은 전투 판정이 아니다.
- 구조물이 플레이어를 즉시 죽일 수 있다면 사전 신호와 회피 가능성이 있어야 한다.

## 금지

- 클라이언트 로컬에서만 확정되는 피격, 사망, 돌파 판정.
- VFX 재생 성공 여부에 의존하는 실제 전투 결과.
- 코드 상수로 박힌 피해량, 탄속, 쿨타임, 넉백 수치.
- 플레이어가 반응할 수 없는 즉시 처치형 기본 공격.
- 3D Rigidbody, 3D Collider, ConfigurableJoint 기반 신규 전투 확장.

## 미결정

- 동시 사망 시 StateAuthority가 단일 결과로 정규화하는 세부 타이브레이크.
- 반사탄 네트워크 스키마·동작은 [50/02 네트워크 truth 표](../50_기술_구조_기준/02_네트워크_truth_표.md) 정본 참조 (2026-04-20 Option A 채택으로 확정).
- 리스폰 직후 무적 프레임은 **1초로 확정** (Q45 D48, [10/02 §리스폰](../10_게임플레이_기준/02_라운드_상태머신.md) · [70/01 SMK-11](../70_검증_체크리스트/01_스모크테스트.md) 참조). 비-리스폰 피격/공격 경직 및 무적 적용 여부는 Q4로 deferred.
