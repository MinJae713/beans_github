# 카드 효과 분류체계

> MVP는 총알/무기 효과 카드만 운용. 캐릭터 능력 카드는 post-MVP (2026-04-20).

이 문서는 카드 효과를 어떤 기준으로 분류하고, 어떤 효과를 MVP 또는 확장 후보로 볼지 정의한다.

카드별 피해량, 쿨타임, 배율, 확률, 지속 시간, 장탄수 같은 구체 수치는 이 문서에 고정하지 않는다. 실제 값은 `CardDefinition`, `CardEffectProfile`, `WeaponProfile`, `BalanceProfile` 같은 프리셋 구현체에서 관리한다.

## 목적

카드는 단순 강화 목록이 아니라, 구간 돌파 패배자/방어자가 다음 전투의 반격 플랜을 바꾸는 장치다.

| 목적 | 의미 |
|---|---|
| 전투 양상 변화 | 같은 무기라도 다음 구간에서 다른 판단을 만들기 |
| 반격 플랜 제공 | 뒤처진 플레이어에게 선택권을 주되 확정 승리 금지 |
| 계열 가독성 | 카드가 어떤 무기/전장/압박 방식과 연결되는지 명확화 |
| 누적 관리 | 카드가 쌓여도 상대 선택지가 사라지지 않게 제한 |
| 프리셋 분리 | 효과 원칙과 수치 구현을 분리 |

## 카드 효과 대분류

| 분류 | 역할 |
|---|---|
| 투사체 변형 | 탄도, 반사, 폭발, 관통, 분열 같은 투사체 성격 변경 |
| 발사 리듬 변경 | 재장전, 연사, 장탄, 차지, 발사 후 빈틈의 구조 변경 |
| 위치 압박 강화 | 넉백, 밀어내기, 끌어오기, 경계 압박 강화 |
| 제압/방해 | 짧은 경직, 행동 제한, 시야/조준 흔들기 |
| 생존/회복 | 방어, 회피, 회복, 일시 보호, 리스폰 안정성 |
| 구조물 상호작용 | 반사체, 위험 지형, 발판, 상호작용 오브젝트와 연결 |
| 이동/액션 확장 | 점프 강화, 대시, 2단점프 같은 확장 전용 후보. MVP 카드 풀에서는 제외 |

MVP 우선순위는 투사체 변형, 발사 리듬 변경, 위치 압박 강화다. 이동/액션 확장은 액션성을 키우는 방향으로 고려하되, MVP 탄환 후보와 섞어 범위를 흐리지 않는다.

딱밤, 혹, 이모트, 승리 연출처럼 감정을 강화하는 요소는 카드 효과 대분류에 넣지 않는다. 이 요소들은 `입력 행동 규칙`의 기본 기믹 행동 또는 `피드백/UI/연출` 문서의 presentation 트랙에서 관리한다.

## 카드 등급 기준

카드 등급은 희귀도 장식이 아니라 게임 구조에 미치는 영향의 크기를 나타낸다.

| 등급 | 기준 |
|---|---|
| 일반 | 기존 총알 운용을 소폭 바꾸며 조합 충돌이 거의 없음 |
| 희귀 | 일반보다 변화가 크지만 전투 축 하나 안에서 통제 가능한 변화 |
| 에픽 | 탄환 성질, 리듬, 구간 대응 방식을 뚜렷하게 바꿈 |
| 레전더리 | 게임 시스템 자체의 판단을 바꿀 수 있어 보유/조합 제한 필요 |

희귀, 에픽, 레전더리는 단순히 더 센 카드가 아니라 전투 체계를 바꾸는 정도가 다른 카드다. 따라서 보유 수 제한, 중복 제한, 배타 조합 체크가 필요하다.

MVP에서는 모든 등급이 처음부터 등장할 수 있다. 단, 희귀/에픽/레전더리는 낮은 제시 가중치와 보유 제한으로 통제한다. 특정 시간 이후 해금, 구간 이후 해금처럼 복잡한 해금 규칙은 MVP에서 우선 사용하지 않는다.

## 보유 제한 기준

- 카드가 제한 없이 누적되면 패배자 보정이 아니라 통제 불가능한 성장 시스템이 된다.
- 카드 보유 수는 제한하는 방향을 기본으로 한다.
- 카드 보유 수는 티어별 제한을 둔다.
- 희귀/에픽/레전더리는 보유 제한을 둔다.
- 티어별 정확한 보유 수는 기준문서에 고정하지 않고 카드 프리셋 또는 BalanceProfile에서 관리한다.
- MVP baseline 프리셋 후보에서는 에픽은 최대 2장, 레전더리는 최대 1장으로 시작한다.
- 일반급 또는 낮은 영향도의 탄환 보조 카드는 조합 충돌이 적어도, 누적 결과가 TTK와 네트워크 부하를 과하게 바꾸면 제한한다.
- 카드를 받기 위해 일부러 죽는 전략이 유리해지면 지급 시점 또는 등급 확률을 조정한다.

## 카드 지급 트리거

- MVP 기준 카드 지급은 구간 돌파 패배 시 발생한다.
- 모든 일반 사망에 카드를 지급하지 않는다.
- 상대가 만든 일반 전투 사망에 제한적으로 카드를 지급할지는 보류한다.
- 고의 사망으로 강한 카드를 받는 전략이 유리해지면 지급 트리거 또는 지급 횟수 제한을 조정한다.

## 카드 3장 제시 정책

카드 선택 UI는 3장 제시를 기본으로 한다.

| 정책 | 기준 |
|---|---|
| 제시 수 | 3장 |
| 같은 제시 내 중복 | 금지 |
| 이미 최대치에 도달한 카드 | 제외 |
| 티어 보유 제한을 초과하는 카드 | 제외 |
| 희귀도 처리 | 모든 등급이 처음부터 가능하되, 프리셋 가중치로 제어 |
| 선택 확정 | StateAuthority 검증 후 확정 |

카드 제시 정책은 UI 장식이 아니라 밸런스와 네트워크 truth에 직접 영향을 준다. 따라서 후보 생성은 로컬 UI가 임의로 확정하지 않고 authoritative 검증 가능한 입력으로 관리한다.

## 카드 효과가 바꿔야 하는 것

- 플레이어가 잡아야 하는 위치.
- 상대가 피해야 하는 탄도나 압박 방향.
- 재장전과 탄 소모의 판단.
- 구간 돌파 또는 방어의 우선순위.
- 구조물 사용 방식.
- 다음 라운드의 반격 플랜.

## 카드 효과가 바꾸면 안 되는 것

- 상대가 반응할 수 없는 즉시 처치.
- 기본 조작이 망가질 정도의 장기 입력 봉쇄.
- 특정 구간에서 방어 불가능한 확정 루프.
- 모든 무기 계열을 같은 방식으로 올리는 단순 수치 강화.
- network truth 없이 클라이언트별로 다른 결과를 만드는 효과.

## 분류별 설계 기준

### 투사체 변형

| 기준 | 내용 |
|---|---|
| 역할 | 탄도와 공간 제어 방식 변경 |
| 예시 방향 | 반사, 곡사, 폭발, 분열, 관통 후보 |
| 대응 | 사전 신호, 위치 변경, 엄폐, 발사 후 빈틈 |
| 금지선 | 읽히지 않는 피격, 반응 불가능한 즉발 판정 |

투사체 변형 카드는 Colosseum의 MVP 탄환 후보와 가장 직접적으로 연결된다.

상태 이상탄은 투사체 변형과 제압/방해 사이에 걸친 확장 후보로 본다. 얼음, 독, 화상, 마비는 효과가 직관적이지만 누적과 네트워크 truth 부담이 커질 수 있으므로 MVP 포함 여부를 따로 결정한다.

### 발사 리듬 변경

| 기준 | 내용 |
|---|---|
| 역할 | 발사/재장전/빈틈의 리듬 변경 |
| 예시 방향 | 느리지만 큰 보상, 빠르지만 자원 관리 어려움, 차지형 후보 |
| 대응 | 탄 소모 유도, 재장전 압박, 발사 후 진입 |
| 금지선 | 빈틈 없는 무한 압박 |

발사 리듬은 TTK를 직접 건드릴 수 있으므로 `TTK 판단 프레임`과 함께 검토한다.

### 위치 압박 강화

| 기준 | 내용 |
|---|---|
| 역할 | 벽 몰이, 구석 압박, 카메라/경계 압박 강화 |
| 예시 방향 | 넉백 강화, 밀어내기, 짧은 끌어오기 후보 |
| 대응 | 거리 유지, 점프 탈출, 엄폐, 전선 역전 |
| 금지선 | 한 번 맞으면 경계 이탈이 확정되는 구조 |

위치 압박 카드는 체력 삭제보다 구간 돌파와 방어 구조를 바꾸는 쪽이 우선이다.

### 제압/방해

| 기준 | 내용 |
|---|---|
| 역할 | 다음 킬각을 만들기 위한 짧은 행동 제한 |
| 예시 방향 | 짧은 경직, 조준 흔들기, 이동 둔화 후보 |
| 대응 | 거리 관리, 선제 회피, 회복 타이밍 |
| 금지선 | 장기 입력 봉쇄, 무한 경직 |

제압은 처치가 아니라 처치 기회를 만드는 도구로 다룬다.

### 생존/회복

| 기준 | 내용 |
|---|---|
| 역할 | 밀리는 플레이어가 다음 교전에 진입할 시간을 벌기 |
| 예시 방향 | 방어, 짧은 보호, 제한적 회복 후보 |
| 대응 | 보호가 빠진 뒤 압박, 위치 선점 |
| 금지선 | 돌파를 불가능하게 만드는 무한 방어 |

생존 카드는 방어자를 살리는 장치가 될 수 있지만, 전장 진행을 멈추는 장치가 되면 안 된다.

### 구조물 상호작용

| 기준 | 내용 |
|---|---|
| 역할 | 구간 패턴과 카드 선택을 연결 |
| 예시 방향 | 반사체 강화, 위험 지형 활용, 발판 타이밍 후보 |
| 대응 | 구조물 회피, 다른 경로 선택, 구조물 먼저 처리 |
| 금지선 | 맵에 따라 카드가 무조건 승리하는 구조 |

구조물 상호작용 카드는 `구조물 기믹 기준`과 `구간 패턴 카탈로그`를 함께 따라야 한다.

### 이동/액션 확장

| 기준 | 내용 |
|---|---|
| 역할 | 액션성을 키우고 위치 싸움의 선택지를 넓힘 |
| 예시 방향 | 점프 강화, 대시, 2단점프 후보 |
| 대응 | 착지 압박, 자원 소모 유도, 이동 후 빈틈 |
| 금지선 | 기존 구간 패턴과 카메라/경계 규칙을 무력화 |

이동/액션 확장은 좋은 방향이지만, MVP 카드 풀에는 넣지 않고 탄환 후보와 별도 확장 트랙으로 관리한다.

## 누적 방식

카드가 여러 장 쌓일 때는 아래 방식 중 하나로 명시한다.

| 방식 | 의미 |
|---|---|
| 대체형 | 기존 효과를 다른 효과로 바꿈 |
| 확장형 | 기존 역할을 유지하면서 선택지를 추가 |
| 조건형 | 특정 상황, 구간, 행동에서만 의미가 커짐 |
| 상쇄형 | 상대 전략에 대응하는 카운터 역할 |

누적 방식은 카드 UI보다 먼저 결정되어야 한다. 같은 UI라도 누적 규칙이 다르면 게임 양상이 크게 달라진다.

## 배타 조합 기준

- 일반급과 낮은 영향도의 보조 카드는 대체로 조합 충돌이 적다.
- 에픽/레전더리 카드끼리는 같은 전투 축을 과도하게 증폭할 수 있으므로 배타 관계를 먼저 검토한다.
- 예를 들어 곡사형 탄환에 과도한 탄속 증가가 붙으면 곡사형의 약점이 사라질 수 있다.
- 배타 조합은 금지 목록이 아니라 체크리스트로 관리하고, 플레이테스트에서 유지/해제 여부를 판단한다.

## MVP 카드 작성 체크

새 카드 후보를 만들 때는 아래 질문에 답해야 한다.

| no | 질문 |
|---|---|
| 1 | 이 카드는 어떤 전투 양상을 바꾸는가? |
| 2 | 어떤 탄환 후보 또는 구간 패턴과 연결되는가? |
| 3 | 상대가 보고 대응할 신호와 시간이 있는가? |
| 4 | 누적되었을 때 상대 선택지를 지우지 않는가? |
| 5 | 수치 조정 없이도 역할이 설명되는가? |
| 6 | StateAuthority가 결과를 확정할 수 있는 구조인가? |

## 구현 연결

- 카드 효과는 `CardDefinition` 또는 동등한 프리셋에서 정의한다.
- 전투 결과에 영향을 주는 효과는 StateAuthority 기준으로 처리한다.
- 투사체, 넉백, 경직, 체력, 탄약, 쿨타임에 영향을 주는 효과는 network truth와 연결한다.
- VFX, 감정 표현, 혹/딱밤 같은 승리감 연출은 카드 효과가 아니라 presentation 또는 기본 기믹 행동으로 분리한다.
- 수치값은 코드 상수나 기준문서가 아니라 프리셋에서 관리한다.
- 첫 playable slice에서는 이동 액션형 카드를 선택 풀에서 제외한다. 탄환 변화형과 발사 리듬형은 후보 수를 인위적으로 제한하지 않고 함께 검증할 수 있다.
- 카드 등급, 티어별 보유 제한, 중복 제한, 배타 태그는 카드 데이터 구조에 포함되어야 한다.
- 카드 선택은 “총알을 컨트롤한다”는 설명을 UI와 로그에서도 유지해야 한다.

## 금지

- 카드 전체 목록을 이 문서에서 확정하는 것.
- 실제 피해량, 쿨타임, 배율을 이 문서에 고정하는 것.
- ROUNDS식 카드 UI 자체를 차별점처럼 설명하는 것.
- 한 카드가 반응 불가능한 즉시 승리를 만드는 것.
- 이동기 확장을 MVP 탄환 후보와 섞어 범위를 흐리는 것.
- 승리감 연출, 감정 표현, 딱밤/혹 표현을 카드 효과 후보로 등록하는 것.

## 미결정

- 상대가 만든 일반 전투 사망에 제한적으로 카드를 지급할지.
