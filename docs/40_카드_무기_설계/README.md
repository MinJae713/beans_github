# 카드 무기 설계 문서 구조

이 디렉토리는 카드와 무기의 기준, 후보 카탈로그, 구현 가이드를 관리한다.

MVP의 핵심 전제는 “카드는 총알과 발사 양상을 바꾼다”이다. 이동 성장, 승리감 연출, 딱밤/혹 같은 presentation 요소는 카드 효과로 넣지 않는다.

문서 목록의 `성격`은 계층상 역할을 뜻한다. 실제 문서 상태와 binding 범위는 `05_문서관리_규칙/08_문서_상태_인덱스.md`를 우선한다.

## 구조

| 위치 | 역할 |
|---|---|
| 루트 문서 | 카드/무기 철학, 효과 분류 기준, 금지선 |
| `10_세부설계` | MVP 무기 후보, 카드 후보, 상성 매트릭스 |
| `30_구현가이드` | 카드 선택, 네트워크 검증, 확정 흐름 |
