# 40장 카드 카탈로그

> 상태: candidate. 이 문서는 MVP16과 확장 24장을 합친 전체 카드 후보 카탈로그다. 카드 목록, key, 표시명, 희귀도, maxStack, primary category, 핵심 효과를 정리한다. 상세 수치, 등장 확률, 쿨타임, 피해량 배율은 이 문서에 고정하지 않고 `85_밸런스_프리셋` 또는 구현 데이터 프리셋에서 관리한다.

관련 Jira: `S14P31A303-205` 대표. 카드 설계 묶음은 `S14P31A303-205`부터 `S14P31A303-211`까지 연결될 수 있다.

## 목적

이 문서는 40장 전체 카드의 공통 카탈로그다.

MVP16은 기본 탄환 조작, 상태이상 4종, 폭발, 벅샷, 반사/관통, 안티-그래비티를 먼저 보여준다. 확장 24장은 MVP16을 단순히 더 세게 만드는 카드가 아니라, 40장 전체에서 빌드 방향을 넓히는 카드로 둔다.

수치 설계는 MVP16 구현 이후에 진행한다. 기본 이동감, 점프감, 탄속, 포물선 낙차, 기본 TTK가 실제 플레이로 확인되기 전에는 확장 카드 수치를 확정하지 않는다.

## 적용 범위

이 문서에서 확정하는 것:

- 40장 후보 목록
- `cardId`
- 기능형 snake_case `key`
- 플레이어 표시명
- 희귀도
- `maxStack`
- primary category
- 핵심 효과 한 줄

이 문서에서 확정하지 않는 것:

- 피해량, 쿨타임, 배율, 확률, 지속 시간
- 카드 제안 가중치
- 티어별 보유 제한의 최종값
- VFX, SFX, 아이콘 리소스
- Unity 구현 API 이름

## 설계 주의 카드

아래 카드는 구현 불가가 아니라, 구현 전 추가 정책이 필요한 카드다.

| 카드 | 주의점 |
|---|---|
| ICBM | 조준 좌표 확정 시점과 StateAuthority 검증 규칙이 필요하다. |
| 경화 | 피격 무적이지 완전 무적이 아니다. 낙사, 경계 이탈, 라운드 규칙은 막지 않는다. |
| 분열탄 | 반사탄과 함께 있을 때 벽 충돌 우선순위가 필요하다. |
| 지연폭발 | 폭발탄과 함께 있을 때 즉시 폭발과 지연 폭발의 관계가 필요하다. |
| 웨폰 마스터 | 점프, 대쉬, 회복, 상태이상은 포함하지 않는다. |
| 유리대포 | 직접 피해와 최대 체력만 건드린다. |

## 수치 설계 시점

확장 24장의 상세 수치는 MVP16 구현 이후에 설계한다.

수치 설계 전에 확인할 것:

1. 기본 체력과 한 탄창 기준 TTK
2. 기본 탄속과 포물선 낙차
3. 기본 장전 시간과 수동 장전 조작감
4. 기본 점프 높이와 카메라/경계 안정성
5. 상태이상 4종의 UI 가독성
6. 반사/관통/폭발/벅샷 조합의 피격 로그
