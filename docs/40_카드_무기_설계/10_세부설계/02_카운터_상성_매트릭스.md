# 카운터 상성 매트릭스

이 문서는 무기와 카드가 서로 어떤 전투 양상을 만들고, 어떤 대응 관계를 가져야 하는지 정의한다.

피해량, 쿨타임, 탄속, 장탄수, 넉백량 같은 구체 수치는 이 문서에 고정하지 않는다. 실제 상성 강도는 `WeaponProfile`, `CardEffectProfile`, `GameplayProfile`과 플레이테스트 기록에서 조정한다.

## 목적

카운터 상성은 특정 무기 하나가 모든 구간과 모든 상황에서 최선이 되는 것을 막기 위한 설계 도구다.

| 목적 | 의미 |
|---|---|
| 선택 이유 만들기 | 패배자/방어자가 다음 전투에서 다른 플랜을 고르게 함 |
| 단일 정답 방지 | 모든 구간에서 같은 무기만 고르는 상황을 막음 |
| 구간과 연결 | 무기 선택이 구간 패턴에 따라 달라지게 함 |
| 누적 폭주 방지 | 카드가 쌓여도 상대 대응 루트가 남게 함 |
| 플레이테스트 해석 | 승패 원인이 실력, 구간, 무기, 카드 중 어디인지 분리 |

## MVP 무기 후보의 역할

| 후보 | 강점 | 약점 |
|---|---|---|
| 기본탄 운용 | 기준 전투, 탄 관리, 위치 싸움 | 특수 상황 돌파력은 낮음 |
| 넉백 산탄 | 벽 몰이, 구석 압박, 근거리 돌파 | 거리 관리와 빗나간 뒤 빈틈에 약함 |
| 반사탄 | 엄폐 뒤 각도 압박, 좁은 구간 | 개방 공간과 빠른 위치 변경에 약함 |
| 곡사탄 | 엄폐 뒤 압박, 위치 예측 | 근거리 난전과 빠른 돌파에 약함 |
| 저격탄 운용 | 긴 시야 보상, 한 발의 긴장감 | 시야 차단과 발사 실패 후 역진입에 약함 |

이 표는 잠금 목록이 아니라 후보 역할 정의다. 첫 playable slice는 후보 개수를 인위적으로 제한하지 않고, 각 후보가 어떤 전투 질문을 만드는지 검증한다.

## 상성 축

| 상성 축 | 의미 |
|---|---|
| 거리 | 근거리 압박, 중거리 교전, 장거리 시야 보상 |
| 지형 | 개방 공간, 엄폐, 좁은 통로, 고저차 |
| 리듬 | 빠른 연사, 느린 고보상, 재장전 빈틈, 차지 |
| 위치 압박 | 넉백, 벽 몰이, 구간 돌파, 경계 압박 |
| 예측 난도 | 직선, 반사, 곡사, 탄착 예고 |

상성은 숫자가 아니라 이 축의 조합으로 먼저 설명되어야 한다.

## 매트릭스 초안

| 공격 플랜 | 잘 먹히는 상황 | 약한 상황 | 대응 플랜 |
|---|---|---|---|
| 기본탄 운용 | 기준 구간, 중거리 교전 | 엄폐 뒤 각도전, 강한 벽 몰이 | 탄 소모 유도, 엄폐 전환 |
| 넉백 산탄 | 벽 몰이, 구석 압박(경계 이탈 자체는 Q41 D45로 무효화되어 clamp 처리, [10/02](../../10_게임플레이_기준/02_라운드_상태머신.md) 참조) | 개방 공간, 거리 유지 | 거리 벌리기, 재장전 압박 |
| 반사탄 | 엄폐 뒤 각도전 | 개방 공간, 빠른 이동 | 각도 회피, 위치 변경 |
| 곡사탄 | 엄폐 뒤 대치 | 근거리 난전, 빠른 진입 | 전진 압박, 탄착 회피 |
| 저격탄 운용 | 긴 시야, 진입 억제 | 시야 차단, 다층 엄폐 | 시야 끊기, 발사 후 진입 |

## 좋은 상성의 조건

- 상대가 대응 행동을 알고 시도할 수 있다.
- 구간 패턴이 상성을 너무 한쪽으로 고정하지 않는다.
- 강한 무기는 실패했을 때 반격 창구가 분명하다.
- 약한 무기도 특정 구간이나 상황에서는 선택 이유가 있다.
- 카드 누적 후에도 상대가 완전히 무력화되지 않는다.

## 나쁜 상성의 징후

- 특정 무기가 모든 구간에서 항상 선택된다.
- 이긴 쪽이 같은 무기로 계속 스노우볼을 굴린다.
- 패배자가 카드를 받아도 다음 전투 플랜이 바뀌지 않는다.
- 대응이 실력 문제가 아니라 정보 부족이나 반응 불가능으로 보인다.
- 구간 패턴과 무기 후보가 서로를 과도하게 증폭한다.

## 구현 연결

- 무기와 카드에는 단일 역할만이 아니라 다중 태그를 둘 수 있다.
- 태그는 선택 UI 설명, 플레이테스트 로그, 밸런스 분석에서 같은 용어로 쓰는 것이 좋다.
- 상성 평가는 `관찰지표 정의`의 사망 원인, 구간 돌파 원인, 선택 후 전투 양상 변화와 연결한다.
- 첫 playable slice에서는 상성의 완성보다 후보들이 서로 다른 전투 질문을 만드는지 확인한다.

## 배타 상성 체크리스트

카드끼리의 상성은 단순 시너지뿐 아니라 배타 관계도 포함한다. 특히 에픽/레전더리는 조합 전에 아래 질문을 통과해야 한다.

| no | 질문 |
|---|---|
| 1 | 두 카드가 같은 약점을 동시에 지워버리지 않는가? |
| 2 | 탄도 변화와 탄속/연사 변화가 합쳐져 대응 불가가 되지 않는가? |
| 3 | 구간 하나에서 특정 조합이 사실상 확정 승리가 되지 않는가? |
| 4 | 카드 보유 제한을 우회해 레전더리급 효과가 중첩되지 않는가? |
| 5 | 네트워크 truth와 로그에서 조합 원인을 추적할 수 있는가? |

배타 체크를 통과하지 못한 조합은 금지하거나, 대체형 카드로 처리하거나, 같은 등급 슬롯을 공유하게 만든다.

## 금지

- 이 문서에서 승률 목표나 수치 보정값을 확정하는 것.
- 카운터를 “완전 무효화”로 설계하는 것.
- 상성 때문에 패배자가 오히려 선택권을 잃는 구조.
- 구간 패턴 하나가 특정 무기 하나의 전용 무대가 되는 구조.
- 에픽/레전더리 조합 충돌을 데이터 태그 없이 사람 기억에만 의존하는 것.
