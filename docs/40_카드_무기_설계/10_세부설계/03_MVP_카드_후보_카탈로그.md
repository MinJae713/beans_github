# MVP 카드 후보 카탈로그

> **MVP 카드는 총알/무기 관련 효과만 포함한다.** 캐릭터 능력 변경(점프·이동속도·리스폰·체력·무기 교체 등) 카드는 밸런스 격변 우려로 post-MVP 이관 (2026-04-20 결정).

이 문서는 MVP에서 검토할 카드 후보를 데이터/프리셋 후보로 정리한다.

이 문서는 기준문서 본문이 아니라, 교체 가능한 세부설계와 프리셋 후보에 가깝다. 따라서 카드명, 역할, 전투 양상, 리스크, 배타 태그를 정리하되 피해량, 탄속, 장전 시간, 쿨타임, 확률 같은 수치는 고정하지 않는다.

## 전제

MVP 카드는 “총기 자체를 교체하는 시스템”이 아니라 “총알 성질과 발사 리듬을 바꾸는 시스템”으로 시작한다.

| 전제 | 적용 방식 |
|---|---|
| 총알 제어 | 탄도, 반사, 넉백, 탄퍼짐, 장전 리듬을 우선한다 |
| 총기 교체 보류 | 무기 외형/종류 교체는 MVP 핵심 차별점으로 삼지 않는다 |
| 이동 성장 보류 | 점프 강화, 2단점프, 대시는 MVP 카드 풀에서 제외한다 |
| 수치 비고정 | 정확한 강함은 BalanceProfile/CardEffectProfile에서 조정한다 |
| 대응 가능성 | 모든 카드에는 상대가 읽고 대응할 신호가 있어야 한다 |
| 전 등급 시작 허용 | 일반/희귀/에픽/레전더리는 처음부터 제시될 수 있으나 가중치와 보유 제한으로 통제한다 |
| 구간 돌파 보상 | MVP 카드 지급은 구간 돌파 패배자를 기본 대상으로 한다 |

## 제시와 보유 제한 프리셋 원칙

| 항목 | 프리셋 기준 |
|---|---|
| 제시 장수 | 3장 |
| 같은 제시 내 중복 | 제외 |
| maxed 카드 | 제외 |
| 티어 제한 초과 카드 | 제외 |
| 희귀도 가중치 | 프리셋에서 조정 |
| 카드 보유 상한 | 티어별로 관리 |
| 정확한 제한 수치 | 이 문서의 MVP baseline 후보로 두고 CardPool/BalanceProfile에서 교체 가능하게 관리 |

희귀/에픽/레전더리는 처음부터 등장할 수 있다. 다만 강한 등급은 낮은 제시 가중치와 강한 티어별 보유 제한으로 통제한다.

## MVP baseline 보유 제한 후보

아래 값은 기준문서의 확정 규칙이 아니라 첫 구현과 플레이테스트를 위한 프리셋 후보다. 실제 구현에서는 `CardPool`, `CardEffectProfile`, `BalanceProfile` 같은 데이터 계층에서 교체 가능해야 한다.

| 티어 | MVP baseline 후보 | 의도 |
|---|---|---|
| 일반 | 낮은 하드캡을 두지 않고 카드별 최대치로 관리 | 기본 조합과 작은 변화는 충분히 체감하게 함 |
| 희귀 | 제한적으로 허용 | 일반보다 전투 양상을 더 바꾸되 에픽보다 부담을 낮춤 |
| 에픽 | 최대 2장 | 전투 양상 변화와 조합 재미를 허용하되 폭주를 막음 |
| 레전더리 | 최대 1장 | 판을 흔드는 카드로 유지하고 중첩으로 시스템이 무너지는 것을 방지 |

에픽을 2장까지 허용하는 이유는 레전더리와 차별을 두기 위해서다. 에픽은 “강한 선택지”이지만 조합의 재미를 만들어야 하고, 레전더리는 “한 장만으로 판의 판단을 바꾸는 선택지”로 둔다.

## 카드 데이터 최소 필드

카드 후보를 구현 데이터로 옮길 때는 아래 필드를 최소 단위로 본다.

| 필드 | 의미 |
|---|---|
| candidate_id | 임시 후보 식별자 |
| 표시명 | 플레이어에게 보여줄 임시 카드명 |
| 카드 축 | 탄환 변형, 발사 리듬, 위치 압박, 제압/방해 등 |
| 후보 등급 | 일반, 희귀, 에픽, 레전더리 후보 중 하나 |
| 전투 양상 | 카드가 바꾸는 플레이 판단 |
| 대응 방법 | 상대가 대응할 수 있는 방법 |
| 배타 태그 | 같이 붙으면 위험한 효과 묶음 |
| 누적 정책 | 중복 허용, 대체, 제한, 보류 중 하나 |
| 구현 단계 | 첫 slice, MVP 확장, 보류 중 하나 |

후보 등급은 확률이나 드랍률이 아니다. 게임 구조에 미치는 영향의 크기를 표시하는 기획 태그다.

## MVP 후보 풀 (W1 시점 baseline 10종, T5 재설계 대상)

> **2026-04-21 T5(D54) 결정**: MVP 카드 카탈로그를 **40장+로 확장**하고 등급 분포·offer-fallback을 재설계한다. 담당 김범승, 마감 **2026-04-27**. 아래 10종은 W1 시점 코드에 구현된 baseline이며 W2에 재설계 대상으로 처리된다. 본 블록은 재설계 완료 후 교체된다.

아래는 W1 시점 코드에 구현된 baseline 10종이다. 수치는 `CardEffectProfile` / `BalanceProfile`에서 관리하며 이 문서에 고정하지 않는다.

| candidate_id | 표시명 | 카드 축 | 후보 등급 | 전투 양상 | 대응 방법 | 배타 태그 | 누적 정책 |
|---|---|---|---|---|---|---|---|
| C-BULLET-BIG | Big Bullet | 투사체 변형 | 일반 후보 | 탄환 크기 ×1.3, 피해 ×1.2. 명중 판정이 커져 회피 여유가 줄어든다 | 거리 유지, 빠른 이동으로 탄 회피 | burst_damage | 제한 |
| C-BULLET-BLAST | Blast Shot | 투사체 변형 | 에픽 후보 | 폭발 반경 2, 스플래시 50%. 엄폐 뒤와 근접 압박에 유효 | 엄폐 포기 후 거리 유지, 폭발 범위 밖 이동 | trajectory | 대체 또는 제한 |
| C-BULLET-RICOCHET | Bouncy | 투사체 변형 | 에픽 후보 | 벽 바운스 추가. 직선 사격이 닿지 않는 각도와 엄폐 뒤를 압박 | 반사각 회피, 위치 변경, 전진 압박 | trajectory, ricochet | 대체 또는 제한 |
| C-BULLET-SHOTGUN | Buckshot | 위치 압박, 탄퍼짐 | 에픽 후보 | 추가 탄환 스프레드. 근거리 공간 제압과 벽 몰이 압박 | 거리 유지, 산탄 사거리 밖 교전, 발사 후 빈틈 진입 | knockback, spread | 대체 또는 제한 |
| C-RHYTHM-LIFESTEAL | Lifesteal | 생존/회복 | 희귀 후보 | 킬 시 체력 회복. 적극 교전 보상을 높이고 역전 기회를 만든다 | 킬 허용 최소화, 거리 유지, 탄 소모 유도 | — | 제한 |
| C-RHYTHM-OVERCHARGE | Overcharge | 발사 리듬 | 희귀 후보 | 재장전 후 다음 탄환 배수. 장전 타이밍에 강한 집중 압박 발생 | 재장전 직후 빈틈 진입, 장전 유도 후 전진 | rhythm, burst_damage | 제한 |
| C-BULLET-PIERCE | Piercing Round | 투사체 변형 | 에픽 후보 | 관통 추가. 얇은 엄폐와 일렬 위치를 압박해 위치 재배치 유도 | 엄폐 위치 변경, 수직 이동, 각도 분산 | trajectory, pierce | 제한 |
| C-RHYTHM-QUICKLOAD | Quick Reload | 발사 리듬 | 일반 후보 | 재장전 속도 ×. 재장전 빈틈을 줄여 지속 압박 | 탄 소모 유도, 장전 전 진입, 구조물 활용 | reload, rhythm | 제한 |
| C-BULLET-IMPACT | Shove | 위치 압박 | 일반 후보 | 넉백 ×. 피격자 위치 손실을 키워 벽 몰이와 경계 압박 | 거리 유지, 점프 탈출, 탄 소모 유도 | knockback | 제한 |
| C-BULLET-SPEED | Speed Shot | 투사체 변형, 발사 리듬 | 일반 후보 | 탄환 속도 ×, 이동속도 ×. 빠른 탄으로 반응 시간을 줄이고 기동성을 높임 | 거리 압축 전진, 엄폐 교대, 탄 소모 유도 | rhythm | 제한 |

새 후보를 추가할 때는 아래 체크리스트와 배타 태그를 채우고, 후보가 많아질수록 플레이테스트 리포트에서 어떤 축이 문제를 만들었는지 추적할 수 있어야 한다.

## 보류 후보 (post-MVP 이관)

아래 후보는 재미 가능성은 있지만 MVP 카드 풀에 바로 섞으면 전투 원인 분리가 어려워진다. 상세 목록은 [90_백로그/01_협업기준_이후_백로그.md](../../90_백로그/01_협업기준_이후_백로그.md)의 “Post-MVP 카드 후보” 섹션을 참조한다.

| 후보 | 보류 이유 |
|---|---|
| 점프 높이 상승 | 구간/카메라/경계 규칙과 TTK를 크게 흔든다 |
| 2단점프 | 전장 압박과 구조물 대응법을 다시 설계해야 한다 |
| 대시 강화 | 기본 이동기로 둘지 특수 행동으로 둘지 먼저 결정해야 한다 |
| 리스폰 시간 감소 | 전투 카드가 아니라 라운드 흐름 카드에 가깝다 |
| 체력/방어 지속 성장 | 구간 돌파를 멈추는 방어 메타를 만들 위험이 있다 |
| 상태 이상탄 | 네트워크 truth, 누적, 가독성 부담이 크다 |
| 레이저/즉발 공격 | 투사체 전제와 충돌하고 반응 가능성이 낮다 |
| 이동속도 변경 (캐릭터 능력) | 총알 제어 전제와 분리된 캐릭터 능력 카드 |
| 무기 교체 | MVP 핵심 차별점 아님, 확장 백로그 |

보류 후보는 폐기가 아니다. MVP의 “총알 제어” 전제가 검증된 뒤 별도 트랙에서 다시 평가한다.

## 배타 태그 기준

배타 태그는 카드 조합을 막기 위한 확정 목록이 아니라, 위험한 조합을 검토하기 위한 표시다.

| 태그 | 의미 | 주의할 조합 |
|---|---|---|
| baseline | 비교 기준 | 드래프트 카드처럼 누적하지 않음 |
| knockback | 위치 손실 강화 | 산탄, 경계 압박, 짧은 구간과 결합 시 확정 이탈 위험 |
| trajectory | 탄도 변화 | 반사, 곡사, 관통이 동시에 붙으면 가독성 하락 |
| ricochet | 반사 | 반사 횟수, 탄속, 피해 보상이 겹치면 억울함 증가 |
| arc | 포물선 | 탄속 보정과 결합하면 약점이 사라질 수 있음 |
| pierce | 관통 | 엄폐/구조물 의미를 지울 수 있음 |
| rhythm | 발사/장전 리듬 변화 | 빠른 재장전과 많은 탄이 겹치면 빈틈 없는 압박 위험 |
| range | 장거리 보상 | 저격과 큰 보상이 겹치면 반응 불가 킬각 위험 |
| burst_damage | 한 발 보상 | TTK를 급격히 줄일 수 있어 별도 검증 필요 |
| projectile_count | 투사체 수 증가 | 네트워크 부하와 화면 가독성 리스크 |
| reload | 재장전 변경 | 탄 소모 판단이 사라지지 않도록 검증 필요 |

## 구현 단계별 권장 풀

| 단계 | 권장 후보 | 목표 |
|---|---|---|
| 후보 등록 | 개수 제한 없이 후보를 카탈로그에 추가 | 아이디어를 잃지 않고 축/태그/리스크를 기록 |
| 첫 구현 slice | 구현자가 처리 가능한 최소 묶음 선택 | 네트워크, UI, 카드 적용 파이프라인 검증 |
| 플레이테스트 slice | 특정 카드 축 또는 조합 묶음 선택 | 전투 양상 변화, 대응 가능성, 과도한 스노우볼 확인 |
| 안정화 slice | 문제 후보 조정, 배타 태그/티어 제한 적용 | TTK와 카드 선택 비율 안정화 |

각 단계는 후보 개수 확정이 아니라 운영 방식이다. 후보 풀은 열어두되, 테스트 목적 없이 모든 후보를 한 번에 검증하려고 하면 원인 분석이 불가능해진다.

## 카드 후보 작성 체크리스트

새 후보를 추가할 때는 아래 항목을 채운다.

| no | 질문 |
|---|---|
| 1 | 이 카드는 총알 성질 또는 발사 리듬을 바꾸는가? |
| 2 | 이 카드는 어떤 킬각을 만든다: 위치, 쿨타임/점프 소모, 체력 중 무엇인가? |
| 3 | 상대가 보고 대응할 수 있는 신호가 있는가? |
| 4 | 누적되었을 때 상대 선택지를 지우지 않는가? |
| 5 | 특정 구간 하나에서만 정답 카드가 되지 않는가? |
| 6 | StateAuthority가 결과를 확정할 수 있는가? |
| 7 | 수치 없이도 역할이 설명되는가? |

## 미결정

- 넉백 산탄과 충격탄을 별도 카드로 둘지, 같은 계열의 단계형 후보로 둘지.
- 저격탄 운용을 탄환 카드로 볼지, 별도 무기 운용 프리셋으로 볼지.
- 상태 이상탄을 언제 총알 확장 후보로 승격할지.
