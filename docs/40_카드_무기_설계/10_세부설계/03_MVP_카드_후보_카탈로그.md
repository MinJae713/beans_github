# MVP16 카드 후보 카탈로그

> 상태: candidate. 이 문서는 MVP에서 먼저 검증할 16장 카드 후보를 정리한다. 카드별 수치, 등장 확률, 쿨타임, 피해량 배율은 이 문서에 고정하지 않고 `85_밸런스_프리셋` 또는 구현 데이터 프리셋에서 관리한다.

## 변경 배경

2026-04-21 T5(D54)에서 MVP 카드 카탈로그를 넓히고 등급 분포와 offer fallback을 재설계하기로 했다. 현재 정리된 기준은 MVP 우선 검증 16장과 확장 24장을 합친 전체 40장 후보이며, W1 시점 코드에 있던 baseline 10종은 현재 기준이 아니라 과거 구현 관찰값이다.

현재 문서의 기준은 아래와 같다.

- MVP 우선 검증 카드: 16장
- 전체 후보 카탈로그: [04_40장_카드_카탈로그.md](04_40장_카드_카탈로그.md)
- 정확한 수치와 제안 가중치: `85_밸런스_프리셋`에서 관리

## 전제

MVP 카드는 “총기 자체를 교체하는 시스템”이 아니라 “총알 성질과 발사 리듬을 바꾸는 시스템”으로 시작한다.

| 전제 | 적용 방식 |
|---|---|
| 기본 탄환 | 약한 포물선 탄도 |
| 총알 제어 | 탄도, 크기, 탄속, 반사, 관통, 폭발, 상태이상, 장전 리듬을 우선한다 |
| 총기 교체 보류 | 무기 외형/종류 교체는 MVP 핵심 차별점으로 삼지 않는다 |
| 이동 성장 보류 | 점프 강화, 대쉬 강화 같은 이동 카드는 MVP16에는 넣지 않고 확장 후보로 분리한다 |
| 수치 비고정 | 정확한 강함은 `CardDefinition`, `CardEffectProfile`, `GameplayProfile` 계열에서 조정한다 |
| 대응 가능성 | 모든 카드에는 상대가 읽고 대응할 신호가 있어야 한다 |
| 전 등급 시작 허용 | Common, Rare, Epic, Legendary는 처음부터 제시될 수 있으나 가중치와 보유 제한으로 통제한다 |

## 제시와 보유 제한 원칙

| 항목 | 기준 |
|---|---|
| 제시 장수 | 3장 |
| 같은 제시 내 중복 | 제외 |
| maxed 카드 | 제외 |
| 티어 제한 초과 카드 | 제외 |
| 희귀도 가중치 | 프리셋에서 조정 |
| 카드별 최대 중첩 | `maxStack`으로 관리 |
| 같은 희귀도 내 카드 선택 | 적격 카드 중 균등 추첨을 기본 후보로 둔다 |

희귀도별 제안 비율, 티어별 보유 제한, fallback 정책은 이 문서가 아니라 카드 제안 프리셋에서 관리한다.

## MVP16 설계 메모

- 상태이상 4종은 MVP16에 포함한다. 카드 시스템이 단순 수치 증가만이 아니라 전투 상태를 바꾸는 구조임을 보여주기 위해서다.
- `폭발탄`과 `벅샷`은 조합 파급력이 크므로 Epic으로 둔다.
- `안티-그래비티`는 기본 곡사탄 문법을 깨는 대표 변칙 카드이므로 Legendary로 둔다.
- 무기 변환 카드는 두지 않는다.
- 이동/체력/방어/회복 계열 카드는 MVP16에는 넣지 않고 전체 40장 확장 후보에서 별도로 다룬다.

## W1 baseline 10종 처리

W1 시점 코드에 있던 baseline 10종은 현재 MVP 후보 목록이 아니다.

| W1 이름 | 현재 처리 |
|---|---|
| Big Bullet | `대형탄`으로 재정리 |
| Blast Shot | `폭발탄`으로 재정리 |
| Bouncy | `반사탄`으로 재정리 |
| Buckshot | `벅샷`으로 재정리 |
| Lifesteal | MVP16에서 제외하고 40장 확장 후보 `흡혈탄`으로 이동 |
| Overcharge | `오버차지`로 재정리 |
| Piercing Round | `관통탄`으로 재정리 |
| Quick Reload | `빠른 장전`으로 재정리 |
| Shove | `넉백탄`으로 재정리 |
| Speed Shot | `고속탄`으로 재정리 |

## 구현 단계별 권장 풀

| 단계 | 권장 후보 | 목표 |
|---|---|---|
| 카드 시스템 slice | 대형탄, 빠른 장전, 오버차지 | 카드 적용, maxStack, UI 표시, 재장전 트리거 검증 |
| 투사체 slice | 고속탄, 중량탄, 반사탄, 관통탄 | projectile modifier와 충돌 순서 검증 |
| 상태이상 slice | 중독탄, 화염탄, 냉기탄, 감전탄 | 상태이상 적용, 갱신, UI 가독성 검증 |
| 조합 고점 slice | 폭발탄, 벅샷, 안티-그래비티 | 폭발/다중탄/직선탄 조합과 네트워크 부하 검증 |

각 단계는 후보 개수 확정이 아니라 운영 방식이다. 테스트 목적 없이 모든 후보를 한 번에 검증하려고 하면 원인 분석이 어려워진다.
