# MVP 탄환/무기 후보 정의

이 문서는 MVP에서 우선 검토할 탄환/무기 후보와 각 후보가 만들어야 하는 전투 양상을 정의한다.

피해량, 탄속, 장탄수, 재장전 시간, 쿨타임, 넉백 수치는 이 문서에 고정하지 않는다. 실제 값은 `BalanceProfile`, `WeaponProfile`, 카드/무기 프리셋에서 관리한다.

## 전제

MVP 무기는 화려한 전체 목록이 아니라, 전투 양상 차이를 설명하고 검증하기 위한 최소 후보군이다. 회의 기준 핵심은 총기 자체를 계속 바꾸는 것이 아니라 탄환 성질을 제어하는 것이다.

| 원칙 | 의미 |
|---|---|
| 투사체 기반 | MVP 무기는 기본적으로 투사체 판정을 사용 |
| 탄환 중심 | 총기 교체보다 탄환 성질과 발사 리듬 변화를 우선 |
| 양상 차이 | 각 무기는 다른 압박 방식과 대응법을 가져야 함 |
| 수치 비고정 | 강함은 숫자가 아니라 역할과 리스크로 먼저 설명 |
| 대응 가능성 | 맞는 쪽이 사전 신호와 회피 가능성을 가져야 함 |
| 확장 여지 | 이동기 카드는 후보로 남기되 MVP 핵심 무기는 아님 |

## MVP 후보 목록

| 후보 | 계열 | 만드는 양상 | 주요 대응 |
|---|---|---|---|
| 기본탄 운용 | 결투형 | 정면 교전, 장전 타이밍, 기본기 | 엄폐, 점프, 재장전 압박 |
| 넉백 산탄 | 돌파형 | 벽 몰이, 구석 압박, 구간 돌파 | 거리 유지, 탄 소모 유도 |
| 반사탄 | 제압형 | 각도 싸움, 엄폐 뒤 압박 | 위치 변경, 반사각 회피 |
| 곡사탄 | 곡사형 | 고저차/엄폐 뒤 공간 장악 | 이동 예측 회피, 전진 압박 |
| 저격탄 운용 | 저격형 | 긴 사거리 타이밍 보상 | 시야 끊기, 발사 후 반격 |

레이저처럼 투사체가 아닌 즉발형 무기는 MVP 후보에서 제외한다. 이동기인 점프 상승, 대시, 2단점프는 액션성 확장 후보로 남기되, 무기 후보 목록과 분리한다.

## 탄환 카드 후보군

아래 후보는 “총 종류”가 아니라 기본 총에 얹히는 탄환 성질 또는 발사 리듬 후보로 본다.

| 후보군 | 설계 의미 |
|---|---|
| 충격탄 | 넉백과 위치 압박을 키워 구간 돌파/낙사 각을 만듦 |
| 반사탄 | 한 번 튕기는 탄으로 엄폐와 각도 싸움을 만듦 |
| 곡사탄 | 포물선 탄도로 고저차와 엄폐 뒤를 압박 |
| 상태 이상탄 | 얼음, 독, 화상, 마비 같은 확장 후보 |
| 장전/탄수 계열 | 대탄, 퀵탄, 많은 약한 탄, 묵직한 한 발의 리듬 변화 |
| 유리 대포 계열 | 큰 보상과 큰 리스크를 주는 확장 후보. MVP 밖 우선 |

상태 이상탄과 유리 대포 계열은 재미 후보지만 MVP 범위를 과도하게 넓힐 수 있다. 후보 수 자체는 제한하지 않되, 첫 playable slice에서는 원인과 결과가 읽히는 후보를 카드 축/태그 단위로 검증한다.

## MVP 구현 우선순위

후보 수는 인위적으로 제한하지 않는다. 다만 구현과 검증은 아래 순서로 쪼개서 진행한다.

| 순서 | 후보 | 목적 | 판단 |
|---|---|---|---|
| 1 | 기본탄 운용 | 모든 비교의 기준점 확보 | 필수 |
| 2 | 넉백/충격 계열 | 위치 기반 킬각과 구간 압박 검증 | 필수 |
| 3 | 반사탄 | 엄폐와 구조물 각도 싸움 검증 | 우선 |
| 4 | 곡사탄 | 고저차/엄폐 뒤 공간 장악 검증 | 우선 |
| 5 | 저격탄 운용 | 긴 사거리와 큰 보상/큰 리스크 검증 | 후순위 |
| 6 | 상태 이상탄 | 얼음, 독, 화상, 마비 등 상태 변화 검증 | MVP 이후 |
| 7 | 유리 대포 계열 | 극단적 보상과 리스크 검증 | MVP 이후 |

저격탄은 뽕맛이 크지만 TTK를 지나치게 짧게 만들 위험이 있다. 따라서 기본탄, 넉백, 반사, 곡사 계열로 대응 가능성과 공간 압박을 먼저 검증한 뒤 넣는다.

## 후보 수 운영

MVP 후보 풀은 열어두되, 한 번의 playable slice에서 모든 후보를 동시에 검증하지 않는다.

| 운영 기준 | 의미 |
|---|---|
| 후보 풀 | 제한하지 않음 |
| 1회 카드 제시 | 3장 |
| 구현 단위 | 카드 축, 티어, 배타 태그, 리스크별 slice |
| 검증 단위 | 후보 개수가 아니라 전투 양상 변화와 대응 가능성 |
| 제외 대상 | maxed 카드, 티어 제한 초과 카드, 같은 제시 내 중복 카드 |

이 방식은 “후보는 넓게, 검증은 좁게” 가져가기 위한 기준이다.

## 후보별 역할

### 기본탄 운용

- 모든 밸런스 비교의 기준점이다.
- 기본 결투형만으로도 최소 전투가 성립해야 한다.
- 기본 결투형이 모든 상황에서 최선이면 카드/무기 선택이 죽는다.

### 넉백 산탄

- 상대를 직접 삭제하기보다 위치를 무너뜨린다.
- 벽 몰이, 구석 압박, 경계 이탈, 구간 돌파와 연결된다.
- 짧은 교전 거리와 탄 소모 리스크가 있어야 한다.

### 반사탄

- 직선 사격만으로 해결되지 않는 공간 싸움을 만든다.
- 반사체, 벽, 좁은 통로와 연결될 때 차별점이 생긴다.
- 반사각이 완전히 읽히지 않으면 억울함이 커진다.

### 곡사탄

- 엄폐 뒤, 고저차, 구조물 뒤를 압박한다.
- 직접 조준보다 위치 예측과 공간 봉쇄가 중요하다.
- 안전하게 숨어서 일방적으로 쏘는 무기가 되면 안 된다.

### 저격탄 운용

- 긴 시야와 타이밍 보상을 크게 가져간다.
- 빗나갔을 때 반격 창구가 분명해야 한다.
- 한 발의 보상이 커도 반응 불가능한 즉사 루프는 금지한다.

## 카드와의 연결

- 패배자가 탄환 성질이나 발사 리듬을 바꿀 때 전투 양상이 달라져야 한다.
- 단순 피해량 증가 카드보다 탄도, 넉백, 재장전 리듬, 반사, 폭발 범위 같은 행동 변화를 우선한다.
- 카드 선택은 ROUNDS식 UI 복제가 아니라, 다음 구간에서 반격 플랜을 바꾸는 장치로 설명한다.
- MVP 카드는 기존 기본 총에 탄환 성질이나 발사 리듬 효과를 얹는 구조를 우선한다. 독립 무기 장착은 확장 후보로 분리한다.
- 첫 playable slice의 후보 범위는 `70_검증_체크리스트/06_첫_Playable_Slice_검증_패킷.md`를 따른다.

## MVP 판단 기준

| 기준 | 질문 |
|---|---|
| 차별성 | 이 무기는 기존 후보와 다른 플레이를 만드는가? |
| 구현 난도 | Fusion 2D 투사체 구조로 빠르게 검증 가능한가? |
| 대응 가능성 | 맞는 쪽이 보고 피하거나 압박할 방법이 있는가? |
| 구조물 연결 | 전장/구간 구조와 상호작용할 수 있는가? |
| 프리셋 분리 | 수치 실험을 코드 수정 없이 할 수 있는가? |

## 금지

- 레이저 같은 즉발 판정을 MVP 기본 후보로 넣는 것.
- 후보 무기를 피해량 차이만으로 구분하는 것.
- 총기 외형/종류 교체를 MVP 카드 차별점으로 설명하는 것.
- 기본 무기를 무조건 약하게 만들고 카드 무기만 재미있게 만드는 것.
- 반응 불가능한 저격/폭발/반사 루프.
- 이동기 확장 후보를 무기 후보와 섞어 MVP 범위를 흐리는 것.

## 미결정

- 독립 무기 장착 UI를 확장 단계에서 별도로 둘지.
- 대탄/퀵탄/연사형/묵직한 한 발을 어떤 후보 등급과 배타 태그로 둘지.
