# 카드 무기 계열 원칙

> 상태: accepted_candidate. 이 문서는 총알 성질과 발사 리듬을 카드의 중심 축으로 보는 방향에 한해 임시 구현 기준으로 사용한다. 문서 상태와 binding 범위는 `05_문서관리_규칙/08_문서_상태_인덱스.md`를 우선한다.

이 문서는 카드와 무기의 계열, 성장 방향, 카운터 구조를 정의한다.

세부 카드/무기 후보는 `10_세부설계`에서 관리하고, 카드별 정확한 수치와 등장 가중치는 `85_밸런스_프리셋`에서 관리한다. 아직 MVP 구현 대상으로 올리지 않은 아이디어만 `90_백로그`에 둔다.

## 설계 목적

- 패배자는 카드를 통해 다음 라운드의 선택지를 얻는다.
- 카드는 단순 화력 증가보다 전투 양상 변화를 만들어야 한다.
- 무기와 카드는 전장 돌파, 구간 방어, 카메라 압박과 연결되어야 한다.
- 카드 누적은 역전 가능성을 주되 일방적 스노우볼을 만들면 안 된다.

## 핵심 전제

Colloseum의 MVP 카드/무기 설계 전제는 “총을 바꾸는 게임”이 아니라 “총알을 컨트롤하는 게임”이다.

| 전제 | 의미 |
|---|---|
| 총알 중심 | 카드의 주 효과는 탄환 성질, 탄도, 리듬, 압박을 바꿈 |
| 총 교체 보류 | 총기 외형/종류 교체는 MVP 핵심이 아니라 확장 후보 |
| 양상 중심 | 피해량 증가보다 위치, 탄도, 장전, 반사, 상태를 바꿈 |
| 배타적 상성 | 강한 카드끼리는 서로 충돌하거나 대체 관계일 수 있음 |

이 전제는 MVP 구현과 발표 설명의 기준이다. 카드 UI가 ROUNDS와 닮아 보이더라도, 차별점은 “패배자가 다음 전투의 총알 운용 방식을 바꾼다”는 데 둔다.

## 무기 계열

| 계열 | 역할 |
|---|---|
| 결투형 | 정면 교전의 안정성과 기본기를 강화 |
| 돌파형 | 전선을 밀고 구간 돌파 각을 만드는 데 강함 |
| 제압형 | 상대 행동을 제한하고 재정비 시간을 벌어줌 |
| 저격형 | 거리와 타이밍 보상을 크게 가져감 |
| 곡사형 | 엄폐, 고저차, 구조물 뒤를 압박함 |

## 계열 우선순위

초기 구현과 밸런스 검증은 아래 순서로 진행한다.

```text
결투형 -> 돌파형 -> 제압형 -> 저격형 -> 곡사형
```

이 순서는 구현 우선순위이지 최종 강함의 순서가 아니다.

## 카드 설계 원칙

| 원칙 | 의미 |
|---|---|
| 양상 변화 | 카드가 전투 판단을 바꿔야 함 |
| 단일 승리 금지 | 카드 한 장이 즉시 승패를 확정하면 안 됨 |
| 누적 제한 | 카드 누적이 상대 선택지를 지우면 안 됨 |
| 계열 연결 | 무기/구간/압박 방식과 카드 효과가 연결되어야 함 |
| 수치 분리 | 효과 수치는 프리셋에서 관리해야 함 |

## 카드가 바꿀 수 있는 축

- 발사 리듬과 재장전 판단.
- 탄도, 반사, 관통, 폭발 같은 투사체 성격.
- 상태 이상, 넉백, 충격 같은 피격 후 결과.
- 탄 수, 장전 방식, 묵직한 한 발과 많은 약한 탄의 선택.
- 방어, 회피, 반격, 생존 타이밍.
- 구간 돌파 압박 또는 구간 방어 능력.
- 이동과 위치 선점은 액션성 확장 후보로 다루되, MVP 총알 체계와 분리한다.

## 카드가 바꾸면 안 되는 축

- 상대가 반응할 수 없는 즉시 처치.
- 기본 조작감을 망가뜨리는 과도한 이동 제한.
- 특정 구간을 사실상 통과 불가능하게 만드는 방어 효과.
- 모든 무기 계열을 같은 방식으로 강화하는 단순 수치 상승.
- 프리셋 밖에서 코드 상수로 박힌 임시 효과.

## 무기와 카드 연결 기준

무기와 카드를 설계할 때는 아래 질문에 답할 수 있어야 한다.

| no | 질문 |
|---|---|
| 1 | 이 선택지는 어떤 킬각을 강화하는가? |
| 2 | 이 선택지는 어떤 압박 방식을 만드는가? |
| 3 | 상대가 대응할 수 있는 신호와 시간이 있는가? |
| 4 | 특정 구간 구조에서만 과도하게 강해지지 않는가? |
| 5 | 수치를 바꾸지 않고도 역할이 설명되는가? |
