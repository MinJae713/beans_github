# 구조물 기믹 기준

이 문서는 전장 안의 구조물, 함정, 반사체, 이동 발판이 전투에 어떤 방식으로 관여할 수 있는지 정의한다.

구조물 위치, 이동 속도, 피해량, 작동 주기, 넉백 수치는 이 문서에 고정하지 않는다. 해당 값은 구간 프리셋, `GameplayProfile`, 구조물 프리셋에서 관리한다.

## 설계 목적

구조물은 단순 배경 장식이 아니라 위치 싸움과 구간 돌파를 바꾸는 장치다. 단, 플레이어가 이해하거나 대응할 수 없는 억울한 사망을 만들면 안 된다.

| 목적 | 의미 |
|---|---|
| 위치 압박 | 벽 몰이, 고저차, 카메라 압박을 강화 |
| 역전 창구 | 밀리는 플레이어가 구조물을 이용해 반격 가능 |
| 전투 양상 변화 | 같은 무기라도 구간마다 다른 판단을 만들기 |
| 승리감 연출 | 상대를 구조물로 몰아넣는 심리적 만족감 제공 |
| 가독성 유지 | 위험과 결과가 화면에서 이해 가능해야 함 |

## 구조물 유형

| 유형 | 역할 |
|---|---|
| 지형 구조물 | 엄폐, 고저차, 벽 몰이, 점프 경로 형성 |
| 이동 발판 | 타이밍 기반 이동 경로와 위험 구간 형성 |
| 반사체 | 투사체 각도와 공간 장악 방식 변경 |
| 위험 지형 | 낙사, 압사, 지속 위험, 접근 제한 |
| 상호작용 오브젝트 | 밀기, 타격, 파괴, 작동으로 전투 흐름 변경 |
| presentation 장식 | 게임 결과를 바꾸지 않는 배경/이펙트 |

## MVP 구조물 범위

MVP에서는 구조물 종류를 넓히기보다, 플레이어가 이해하기 쉬운 위험과 대응을 먼저 검증한다.

| 후보 | MVP 판단 |
|---|---|
| 상호작용 없는 벽 | 포함. 위치 압박, 엄폐, 반사/각도 설계의 기본 |
| 낙사 지형 | 포함 후보. 경계 압박과 구간 돌파 감각 검증 |
| 추 | 포함 후보. 단순하고 읽히는 위험 구조물로 검증 |
| 압사 장치 | P2 후보. 사전 신호와 판정 검수가 준비된 뒤 도입 |
| 밧줄/쇠사슬 절단 | 확장 후보. 추/압사 구조가 안정된 뒤 검토 |

추는 “맞으면 위험하다”는 결과가 명확해야 한다. 쇠사슬은 끊기지 않는 고정 연결, 밧줄은 끊을 수 있는 연결로 구분할 수 있지만, 이 차이는 MVP 이후 압사/절단 판정이 필요해질 때 검토한다.

## 기술 표현 기준

| 표현 | 사용 기준 |
|---|---|
| static Collider2D | 움직이지 않는 지형, 벽, 엄폐 |
| kinematic Rigidbody2D | 정해진 패턴으로 움직이는 발판/장애물 |
| NetworkObject | 결과에 영향을 주고 모든 클라이언트가 같은 상태를 봐야 함 |
| NetworkRigidbody2D | 물리 이동 결과가 네트워크 truth가 되어야 함 |
| local-only | 게임 결과와 무관한 시각/소리/장식 |

신규 구조물은 2D 물리 기준을 따른다. 3D Rigidbody, 3D Collider, ConfigurableJoint 기반 구조물 확장은 금지한다.

## 허용 기준

- 구조물이 사망이나 돌파 결과에 영향을 준다면 StateAuthority가 결과를 확정한다.
- 위험 구조물은 작동 전 사전 신호가 있어야 한다.
- 구조물은 한쪽만 영구적으로 유리하게 만들면 안 된다.
- 구조물은 무기 계열과 상호작용할 수 있어야 한다.
- 구조물은 카메라 범위와 가독성을 해치지 않아야 한다.

## 점프 한도와 종축 구조

본 섹션은 2026-04-30 디자인 결정(D69)에 따라 점프 한도와 종축 구조 가정을 잠근다. 점프 강도·중력 수치는 본 문서에 고정하지 않고 `GameplayProfile`/구조물 프리셋에 위임한다.

| 항목 | 기준 |
|---|---|
| 점프 한도 | 1.5층 (1층→2.5층 가능, 1층→3층 불가) |
| 1.5층 발판 경유 시 3층 도달 | 가능 (디자이너 의도 발판 배치 = 디자인 여지) |
| 1층 | 안전 최하단 — 1층 아래 = 낙사 trigger |
| 점프/대시/공중 부스트 카드 MVP 풀 | 0건 — D25/Q28. 점프 한도를 직접 변경하는 카드 3종(`Dash Knockback`, `Rocket Jump`, `Jump Height Up`)은 카드 asset의 `isDraftEnabled=false`로 MVP 첫 playable slice 카드 선택 풀 제외(2026-05-04 코드 검증). `Anti Gravity`는 풀 포함이나 `cardKey: projectile_gravity_zero` 탄환 trajectory 카드(`jumpForceMultiplier=1`)로 점프 한도와 메커니즘상 무관 → 1.5층 점프 한도가 카드로 깨질 위험 0 |

종축 3층 카테고리 자체는 [30/01 §종축 3층 구조](01_전장_구간_기준.md#종축-3층-구조)와 [30/10/02 §2.5](10_세부설계/02_MVP_첫_전장_명세.md#25-종축-3층-구조)에 정의되어 있다. 본 섹션은 점프 한도와 구조물 설계 가정만 명시한다.

> **A303-317 영향 노트 (2026-05-12)**: 점프 locomotion 튜닝으로 `jumpForce` 12 → 21, `ascendGravityMultiplier` 신규 2.5 적용됨. 이론상 최고 점프 높이가 약 7.45 → 9.06 world unit (약 +22%)로 증가. 1.5층/3층 한도 가정이 깨질 가능성 있어 박병준(레벨디자인 R)·김범승(QA R) 후속 검증 필요. 1.5층 발판 높이 또는 점프 수치 추가 조정 결정은 본 문서에 D-번호로 등록 예정.

## 억울함 방지 기준

| 위험 | 방지 기준 |
|---|---|
| 즉시 압사 | 사전 신호, 회피 경로, 판정 여유 필요 |
| 화면 밖 사망 | 카메라/경계 규칙과 함께 판단 |
| 무한 경직 | 회복 조건과 쿨다운 필요 |
| 일방향 안전지대 | 반격 루트 또는 우회 루트 필요 |
| 예측 불가 반사 | 반사 방향 또는 반사 규칙이 시각적으로 이해 가능해야 함 |

구조물로 죽는 것은 허용하지만, 왜 죽었는지 알 수 없는 구조물은 허용하지 않는다.

## 탄환/카드와의 연결

- 넉백 산탄은 벽 몰이와 낙사/경계 압박을 강화할 수 있다.
- 반사탄은 반사체와 좁은 통로에서 공간 장악을 만든다.
- 곡사탄은 엄폐 뒤와 고저차 구조물을 압박한다.
- 저격탄 운용은 긴 시야와 타이밍 구조물에서 보상을 만든다.
- 기본탄 운용은 구조물 없는 공간에서도 최소 전투가 성립해야 한다.

## 작업 브리핑에 포함할 항목

| 항목 | 작성 기준 |
|---|---|
| 구조물 유형 | 지형/발판/반사체/위험/상호작용/장식 중 어디인지 |
| 결과 영향 | 사망, 넉백, 탄 반사, 이동 경로 중 무엇을 바꾸는지 |
| authority | StateAuthority / NetworkObject / local-only |
| 사전 신호 | 플레이어가 위험을 인지하는 방식 |
| 회피/대응 | 점프, 대시, 엄폐, 반격, 우회 중 가능한 대응 |
| 테스트 관찰점 | 억울함, 가독성, 특정 무기 과강화 여부 |

## 금지

- 플레이어가 반응할 수 없는 즉시 처치 구조물.
- 한쪽 진영만 계속 유리한 고정 구조.
- VFX처럼 보이지만 실제 판정을 숨겨둔 구조물.
- 네트워크 truth 없이 클라이언트마다 다르게 움직이는 전투 구조물.
- 3D 물리 컴포넌트 기반 신규 구조물.
- 점프 한도 1.5층 우회 (1층→3층 직접 도달을 만드는 점프 강도/카드/구조물).
- AIR DASH/공중 부스트 카드 효과를 MVP 풀에 도입.
- 종축 4+ 층 placeholder 도입.

## 미결정

- MVP 첫 구간에 낙사와 추를 모두 넣을지, 하나만 넣을지.
- 파괴 가능한 구조물을 MVP에 포함할지.
- 반사탄 네트워크 스키마는 [50/02](../50_기술_구조_기준/02_네트워크_truth_표.md) 정본 참조 (Option A, 2026-04-20).
- 추의 연결 방식을 단순 고정으로 둘지, 밧줄/쇠사슬 차이까지 표현할지.
