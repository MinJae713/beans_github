# MVPArena 비주얼 컨셉 (v0.1)

> 문서 상태: candidate
> binding 범위: MVPArena 정식 자산 적용(v1.0-demo 발표 빌드 한정)의 시각 톤·팔레트·머티리얼·실루엣·layout 가이드. 우수연(Art R) → 박병준 일시 권한 이관 하의 AD 위임 검수 기준.
> 실행 중단 조건: 본 문서가 accepted gameplay/network truth 또는 [30/01 전장 구간 기준](../01_전장_구간_기준.md), [10/02 라운드 상태머신](../../10_게임플레이_기준/02_라운드_상태머신.md)과 충돌하면 게임플레이 SOT 우선.
> 상태 기준: 문서 상태와 binding 범위는 [05/08 문서 상태 인덱스](../../05_문서관리_규칙/08_문서_상태_인덱스.md)를 우선한다.
> 권한 근거: D## 등록 예정 (v1.0-demo 한정 우수연 → 박병준 R 일시 이관 + AD 위임), [50/05 파일경로별 DRI](../../50_기술_구조_기준/05_파일경로별_DRI.md) 갱신 동반.
> 관련: [45/00 디자인 참조 SOT](../../45_피드백_UI_연출/00_디자인_참조_SOT.md) (HUD/카드/메뉴 흐름은 Figma 우선), [30/10/02 MVP 첫 전장 명세](02_MVP_첫_전장_명세.md).

본 문서는 MVPArena 회색박스 단계에서 발표 빌드 정식 자산으로 격상하기 위한 비주얼 컨셉 SOT다. 우수연(Art R)과 구두 합의된 컨셉을 박제한 candidate이며, post-demo 우수연 R 복귀 시점에 정합화 후 accepted_candidate 승격 검토.

## §1. 톤 / 무드

| 항목 | 값 |
|---|---|
| Setting | **미래 SF** — 우주에 떠 있는 우주선 잔재 위에서 전투 |
| Visual Style | **부드러운 카툰 일러스트** — flat color + 노이즈/grain + 손그림 라인 |
| 톤 | **중립 / 스타일리시** — 쿨톤, 감정 절제. grimdark·핏빛·하드보일드 회피 |
| 캐릭터 영감 | "Dumb Ways to Die" 시각 스타일 영감 (캐릭터는 자체 제작) |

## §2. 단일 컨셉 원칙 ★

> 본 전장은 **단일 컨셉**이다. S1~S7은 우주선 잔재로 이루어진 **동일한 전장**이며, 구간별 시각 차별화는 **layout과 prop 배치로만** 표현한다.
>
> 패턴 매핑(S3 벽 / S4 반사 / S5 시야 / S6 낙사)은 **메커닉 분류**이며, 별도 아트 톤을 의미하지 않는다.

후속 디자이너의 잘못된 외삽(예: "S5는 시야니까 어둡게")을 방지하기 위한 명시적 가드. 게임플레이 fact(전투 발생 위치 등)는 §7에서 다룬다.

## §3. 레퍼런스

본 컨셉은 **2-layer 레퍼런스 구조**다 (ralplan-DR R1 Critic ITERATE 의무 6 정합 — §2 단일 컨셉 원칙은 2-layer 합산이 아니라 각 layer 내부의 내적 단일성을 의미).

### §3-1. Setting + 환경 톤 (단일 layer, 합산 = 100%)

| 우선 | 게임 | 매치 포인트 | 비중 |
|---|---|---|---|
| 1 | **Astroneer** | 우주 SF + 둥근 미니멀 캐릭터 + 부드러운 파스텔 + 그라데이션 행성 | 60% |
| 2 | **Sayonara Wild Hearts** | 보라/마젠타 네온 + 부드러운 일러스트 | 40% |

### §3-2. 캐릭터 실루엣·비례 (별도 IP 영감 layer)

| 영감 | 매치 포인트 | 처리 |
|---|---|---|
| **Dumb Ways to Die** | 콩(bean) 실루엣 + 점 눈 + 라인 미소 + 단순 막대 팔다리 | 시각 영감만 차용, 캐릭터는 자체 제작 (V5 IP 합의 김범승 박제 의무) |

> **2-layer 분리 근거**: Setting 레퍼런스(Astroneer + Sayonara)는 환경/팔레트 layer, DWtD는 캐릭터 실루엣·비례 별도 IP 영감 layer. 두 layer가 서로 독립적이며, 각 layer 내부 단일성만 §2 원칙의 측정 대상이다.

**비매치 (회피)**: 픽셀 아트, 사이버펑크 비/연기, grimdark, 디테일 일러스트풍, 3D PBR.

## §5. 머티리얼 룩

| 항목 | 값 |
|---|---|
| Base | **Flat + 노이즈/grain** — pure flat이 아니라 살짝 distress된 텍스처 오버레이 |
| 셰이딩 | 자체 셰이딩 없음 (flat). 깊이감은 그라데이션 배경과 rim light로만 |
| 윤곽선 | **흰색 / 라이트 시안 1~2px 전방위 outline** — 어떤 배경에서도 일관된 가독성 확보 |
| 라이트 방향 | **무방향 (전방위 rim)** — 시점 변경 없는 사이드뷰라 한 방향 라이트는 부자연스러움 |

## §6. 실루엣 원칙

| 원칙 | 검증 방법 |
|---|---|
| P1 / P2 가독성 | rim light로 배경 명도 차이 확보. 배경 위에 캐릭터를 흑백 변환했을 때 윤곽이 분리되는지 확인 |
| 발판 / 벽 vs 캐릭터 | 명도 차이 ≥ 0.4 (Lab L 채널). 발판은 흙갈 톤(낮은 명도)으로 캐릭터(중간~높은 명도)와 분리 |
| 낙사존 시각 신호 | 배경과 명확히 다른 hue(예: 짙은 보라 + 채도 높은 빨강 액센트)로 사전 경고 |
| prop vs 캐릭터 | prop은 채도 낮음 + 캐릭터는 채도 높음. 캐릭터가 항상 시각 우선 순위 |

## §7. 구간별 layout 가이드

| 구간 | 역할 | 자산 비중 | layout 가이드 |
|---|---|---|---|
| **S1·S7** | VictoryRun, **전투 발생 안 함** | ~25% | 트인 풍경, 행성 풍경 강조, 엔딩 무게감. 오브젝트 적게 |
| **S2~S6** | **모든 전투 발생 (5개 구간)** | ~75% | 같은 prop 라이브러리에서 배치만 차별화 |

> **게임플레이 fact**: S1·S7은 VictoryRun 구간이고 전투가 발생하지 않으며, 모든 전투는 S2~S6에서 발생한다. 자산 작업 시 S1·S7에는 피격/사망/넉백 시각 효과를 고려할 필요 없음.

**자산 라이브러리** (공용, 7~10종, mockup v0.1.2 4차 iter 반영):

| 종류 | 용도 | 사용 패턴 | 비고 |
|---|---|---|---|
| 단차 블록 (T_STP) | 1.5층 발판 (D69 점프 한도 정합) | 모든 전투 구간 공용 | 정적 |
| 비탈길 45° (T_RMP) [신규] | 1F↔1.5F 경사 연결 + 점프 보조 | 모든 전투 구간 공용 | 정적, dir 좌/우 |
| 반사 표면 (T_RFL) | 탄환 반사 시각 표현 | S4 패턴 | 정적 |
| 낙사 신호 (T_VOID) | 사전 경고 (시각만, 청각 보류 Q47) | S6 패턴 | 시각 cue |
| 이동 가능 상자 (P_BOX) [신규 인터랙티브] | 총격 충격력 / 캐릭터 충돌 푸시 | 후속 메커닉 — 게임플레이 SOT 갱신 의무 | **인터랙티브** |
| 장식 prop (P_PIP) | 잔해, 파이프 | 모든 구간 공용 | 정적 |

> ~~시야 차단물 (이전 §7)~~ + ~~장식 prop 잔존 메탈/콘솔 (이전 §7)~~ 2종은 mockup 4차 iter에서 사용 미정 사유로 제거됨 — V7 신규로 박제. S5 시야 자산은 [30/01 전장 구간 기준](../01_전장_구간_기준.md) 합의 후 v0.2 잠금에서 재검토.

**시각 mockup (v0.1 candidate)**: [`assets/mvparena-map-concepts/`](assets/mvparena-map-concepts/README.md) — 4 variants × {1280×720 게임화면, 1080×600 tile library 8 primitives}. **Variant A · ROUNDS-LEAN** 1차 선택 (지형 톤 진중 조정 완료, 2026-05-10 박병준). 8 primitives = T_FLR / T_WAL / T_STP / T_RMP / T_RFL / T_VOID / P_BOX / P_PIP — 발판·벽 base 2종 신규 분리 + 비탈길·상자 2종 신규 추가 + T_BLK·P_ANT 2종 제거 (V7).

> 게임플레이 SOT는 [10/02 라운드 상태머신](../../10_게임플레이_기준/02_라운드_상태머신.md), [30/01 전장 구간 기준](../01_전장_구간_기준.md), [30/10/02 MVP 첫 전장 명세](02_MVP_첫_전장_명세.md) 우선. 본 문서는 그 위의 시각 layer만 정의한다.

## §8. 비매치 / 회피

다음은 본 컨셉과 **명시적으로 충돌**하므로 회피:

- **구간별 색·테마 차별화** — 단일 컨셉 원칙 위반 (§2)
- **3D 모델 / PBR 머티리얼** — [50/04 Fusion 가드레일](../../50_기술_구조_기준/04_Fusion_구현_가드레일.md) 3D 물리 금지선 정합
- **디테일 일러스트풍** (수채·유화) — 부드러운 카툰 톤 위반
- **사이버펑크 비/연기 / 네온 사인** — Sayonara의 컬러 팔레트만 차용, 분위기는 차용 X
- **grimdark / 핏빛 사망 표현** — 중립/스타일리시 톤 위반
- **픽셀 아트** — 일러스트 톤 위반
