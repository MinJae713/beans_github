# 구간 패턴 카탈로그

이 문서는 전장 안의 개별 구간을 어떤 전투 양상으로 설계할 수 있는지 패턴 단위로 정리한다.

구간 길이, 발판 좌표, 카메라 범위, 리스폰 비율, 구조물 속도, 위험 판정 수치는 이 문서에 고정하지 않는다. 실제 값은 구간 프리셋, 레벨 프리셋, `GameplayProfile` 또는 구조물 프리셋에서 관리한다.

## 목적

구간 패턴은 레벨을 빠르게 찍어내기 위한 설계 언어다. 각 구간은 단순히 다른 모양의 맵이 아니라, 다른 압박 방식과 다른 탄환/카드 선택 이유를 만들어야 한다.

| 목적 | 의미 |
|---|---|
| 반복 제작 | 구간을 만들 때 매번 처음부터 고민하지 않음 |
| 양상 분리 | 구간마다 벽 몰이, 고저차, 구조물, 시야 압박을 다르게 줌 |
| 탄환 검증 | 탄환 후보가 실제로 다른 선택지를 만드는지 확인 |
| 억울함 방지 | 패턴마다 위험과 대응법을 함께 정의 |
| 프리셋 연결 | 수치가 아니라 패턴 이름과 목적을 기준으로 실험 |

## 패턴 작성 형식

구간을 새로 만들 때는 아래 항목을 먼저 적는다.

| 항목 | 의미 |
|---|---|
| 패턴 이름 | 구간의 전투 양상을 설명하는 이름 |
| 핵심 압박 | 벽 몰이, 화면 밖 압박, 고저차, 위험 지형 중 중심축 |
| 유효 탄환/카드 | 이 구간에서 의미가 커지는 탄환/카드 계열 |
| 방어자 대응 | 밀리는 쪽이 사용할 수 있는 반격 루트 |
| 돌파자 리스크 | 밀고 있는 쪽이 무리하면 잃는 것 |
| 구조물 truth | static, kinematic, NetworkObject, local-only 중 어디인지 |
| 금지선 | 억울한 사망이나 단일 해법이 되는 조건 |

## MVP 우선 패턴

### 1. 기본 결투 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 정면 교전, 재장전 타이밍, 기본 점프/엄폐 |
| 유효 탄환/카드 | 기본탄 운용, 넉백 산탄 |
| 방어자 대응 | 엄폐, 점프, 탄 소모 유도, 역압박 |
| 돌파자 리스크 | 무리한 전진 후 재장전/위치 손실 |
| 구조물 truth | 주로 static Collider2D |
| 금지선 | 아무 구조물 없이도 기본 전투가 성립해야 함 |

이 패턴은 모든 무기와 카드의 기준점이다. 다른 패턴에서 문제가 생겼을 때 기본 결투 구간과 비교한다.

### 2. 벽 몰이 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 구석 압박, 경계 이탈, 넉백 |
| 유효 탄환/카드 | 넉백 산탄, 제압형 카드 |
| 방어자 대응 | 거리 유지, 점프 탈출, 탄 소모 유도 |
| 돌파자 리스크 | 너무 깊게 들어가면 반격으로 위치가 뒤집힘 |
| 구조물 truth | static Collider2D 또는 단순 NetworkObject |
| 금지선 | 한 번 밀리면 입력 전 사망이 확정되는 구조 금지 |

이 패턴은 Colosseum의 핵심인 위치 기반 킬각을 검증한다.

### 2-1. 낙사 압박 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 경계 압박, 넉백, 구간 돌파와 낙사의 긴장감 |
| 유효 탄환/카드 | 넉백 산탄, 충격탄, 기본탄 운용 |
| 방어자 대응 | 거리 유지, 점프 탈출, 경계 반대편으로 전선 회복 |
| 돌파자 리스크 | 무리한 전진 후 역넉백으로 본인이 위험해짐 |
| 구조물 truth | 위험 판정은 StateAuthority 기준 |
| 금지선 | 한 번 맞으면 조작 전에 낙사가 확정되는 구조 금지 |

낙사는 MVP에서 가장 단순한 위험 지형 후보지만, 구간 돌파와 사망 판정이 섞이기 쉬우므로 상태머신과 함께 검수한다.

### 2-2. 추 위험 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 타이밍 회피, 위치 강제, 짧은 위험 예고 |
| 유효 탄환/카드 | 제압형, 곡사형, 위치 압박 카드 |
| 방어자 대응 | 위험 타이밍 회피, 추 반대편으로 전선 전환 |
| 돌파자 리스크 | 추 타이밍을 무시하고 전진하면 역으로 손해 |
| 구조물 truth | 전투 결과에 영향이면 NetworkObject 또는 authority 판정 |
| 금지선 | 화면 밖에서 갑자기 맞는 추, 예고 없는 즉사 금지 |

추는 MVP 구조물 후보지만, 압사나 절단 가능한 밧줄까지 한 번에 구현하지 않는다.

### 3. 고저차 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 점프 선택, 탄도 선택, 위아래 시야 |
| 유효 탄환/카드 | 곡사탄, 저격탄 운용, 기본탄 운용 |
| 방어자 대응 | 높이 전환, 엄폐, 타이밍 진입 |
| 돌파자 리스크 | 높은 위치를 잡아도 하단 우회나 곡사 압박에 노출 |
| 구조물 truth | static Collider2D, 일부 kinematic Rigidbody2D 가능 |
| 금지선 | 한쪽 위치가 영구 안전지대가 되면 안 됨 |

고저차는 단순 점프맵이 아니라 탄환 후보의 탄도 차이를 드러내는 장치다.

### 4. 반사/각도 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 반사각, 엄폐 뒤 압박, 좁은 통로 |
| 유효 탄환/카드 | 반사탄, 기본탄 운용 |
| 방어자 대응 | 반사각 회피, 위치 변경, 개방 공간으로 이동 |
| 돌파자 리스크 | 반사 예측 실패 시 자기 위치가 노출 |
| 구조물 truth | 반사 결과가 전투에 영향이면 NetworkObject 기준 |
| 금지선 | 반사 방향이 읽히지 않아 원인 불명 피격이 되는 것 금지 |

반사/각도 구간은 반사탄이 단순 피해량 카드가 아니라 공간 제어 수단임을 보여준다.

### 5. 엄폐 압박 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 엄폐 뒤 압박, 이동 예측, 공간 봉쇄 |
| 유효 탄환/카드 | 곡사탄, 곡사형 카드 |
| 방어자 대응 | 엄폐 위치 변경, 전진 압박, 탄착 신호 회피 |
| 돌파자 리스크 | 안전하게 쏘는 동안 전선 주도권을 잃을 수 있음 |
| 구조물 truth | static Collider2D, 위험 효과는 StateAuthority 판정 |
| 금지선 | 엄폐 뒤에서 일방적으로 안전한 공격만 가능한 구조 금지 |

이 패턴은 곡사탄이 "숨어서 맞추는 탄환"이 아니라 위치 예측과 전선 선택의 탄환이 되도록 검수한다.

### 6. 시야 보상 구간

| 항목 | 기준 |
|---|---|
| 핵심 압박 | 긴 시야, 타이밍, 시야 끊기 |
| 유효 탄환/카드 | 저격탄 운용, 기본탄 운용 |
| 방어자 대응 | 시야 차단, 구조물 활용, 발사 후 역진입 |
| 돌파자 리스크 | 빗나간 뒤 반격 창구가 분명함 |
| 구조물 truth | 지형은 static, 시야 보조 연출은 local-only 가능 |
| 금지선 | 반응 불가능한 즉발 처치 구간 금지 |

저격형 구간은 한 발의 보상을 크게 느끼게 하되, 실패와 반격도 명확해야 한다.

## 확장 패턴

| 패턴 | 생성 조건 |
|---|---|
| 이동 발판 구간 | kinematic Rigidbody2D와 네트워크 동기화 기준이 준비된 뒤 |
| 압사 구간 | 사전 신호, 판정 여유, 사망 원인 로그가 준비된 뒤 |
| 구조물 역전 구간 | 상호작용 오브젝트의 authority 기준이 명확해진 뒤 |
| 다층 혼합 구간 | 기본 결투/벽 몰이/고저차가 각각 검증된 뒤 |

확장 패턴은 MVP 첫 구간부터 모두 넣지 않는다. 구조물과 네트워크 truth 검증이 끝난 뒤 추가한다.

## 패턴 조합 원칙

- 한 구간의 핵심 압박은 하나를 우선한다.
- 보조 압박은 핵심 압박을 강화해야 하며, 서로 다른 승리 조건을 동시에 강제하지 않는다.
- 같은 전장 안에서는 패턴이 반복되어도 구조물 배치와 압박 방향을 바꿔야 한다.
- 한 탄환 후보가 모든 패턴에서 최선이 되면 패턴 또는 카드 효과를 조정한다.
- 방어자에게는 최소 하나의 반격 루트가 있어야 한다.

## 구현 연결

- 각 구간 프리셋은 어떤 패턴을 따르는지 메타데이터로 남기는 것이 좋다.
- 구조물이 전투 결과에 영향을 주면 `구조물 기믹 기준`의 truth 분류를 따른다.
- 구간 패턴은 `관찰지표 정의`의 사망 원인 분류와 연결되어야 한다.
- 구간 좌표, 크기, 속도, 위험 판정은 이 문서가 아니라 프리셋에서 관리한다.
- 첫 playable slice의 구간 범위는 `70_검증_체크리스트/06_첫_Playable_Slice_검증_패킷.md`를 따른다.

## 금지

- 수치나 좌표를 이 문서에 최종값처럼 박는 것.
- 특정 무기 하나만 답이 되는 구간.
- 방어자 반격 루트가 없는 일방 압박 구간.
- 화면 밖 사망 원인이 이해되지 않는 구간.
- 3D 물리 컴포넌트가 필요한 구간 패턴.

## 미결정

- 한 전장 안에서 패턴 반복을 어느 정도 허용할지.
- 구간 프리셋 메타데이터를 Unity에서 어떤 구조로 둘지.
