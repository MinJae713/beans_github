# 전장 레벨디자인 문서 구조

이 디렉토리는 전장, 구간, 구조물, 카메라 경계에 대한 기준과 세부설계를 관리한다.

문서 목록의 `성격`은 계층상 역할을 뜻한다. 실제 문서 상태와 binding 범위는 `05_문서관리_규칙/08_문서_상태_인덱스.md`를 우선한다.

## 구조

| 위치 | 역할 |
|---|---|
| 루트 문서 | 전장과 구조물의 기준, 금지선, 판단 원칙 |
| `10_세부설계` | 구간 패턴, 구조물 후보, 최종 구간 연출 후보 |
| `20_검수` | 카메라, 경계, 구간 플레이테스트 체크 기준 |
