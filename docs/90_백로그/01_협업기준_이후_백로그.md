# 협업기준 이후 백로그

이 문서는 중요하지만 지금 확정하지 않는 기획 항목을 보관한다.

현재 1차 목표는 팀의 협업 기준, 문서 구조, AI 협업 운영 원칙, 최소 검증 기준을 먼저 잠그는 것이다. 아래 항목들은 그 기준이 확정된 뒤 별도 기획 세션에서 다룬다.

## 보류 원칙

| 원칙 | 의미 |
|---|---|
| 지금 안 함 | 협업 기준 확정 전에는 세부 확정하지 않음 |
| 잊지 않음 | 중요 항목이므로 백로그에 명시적으로 남김 |
| 분리 진행 | 각 항목은 별도 brief로 범위를 잠근 뒤 진행 |

## 협업 기준 확정 후 진행할 항목

| no | 항목 | 보류 이유 |
|---|---|---|
| 1 | 세부 카드 전체 목록 | 카드 설계 원칙 확정 후 수량과 효과를 정해야 함 |
| 2 | 세부 무기 전체 목록 | 기본 전투/TTK 기준 확정 후 계열을 확장해야 함 |
| 3 | 정확한 밸런스 수치표 | 플레이테스트와 시뮬레이션 없이 고정하면 위험함 |
| 4 | Photon 네트워크 세부 구현 | 로컬 1v1 구조와 authority 기준이 먼저 필요함 |
| 5 | 최종 아트/VFX 룩 | 핵심 게임감과 협업 기준 확정 후 일관되게 정해야 함 |
| 6 | 문서 인덱스/허브 고도화 | 문서가 더 늘어난 뒤 사용 경로 기준으로 정리해야 함 |
| 7 | P1/P2 내부 기준문서 확장 | P0 문서로 실제 구현 흐름을 먼저 검증한 뒤 확장해야 함 |
| 8 | MVP 전투 수치 프리셋 작성 | 기준문서에는 수치를 고정하지 않기로 했으므로 `85_밸런스_프리셋/20_수치프리셋`에 별도 후보가 필요함 |
| 9 | 카드 가중치/티어 제한 프리셋 작성 | 카드 3장 제시 정책은 확정됐지만 rarity weight와 티어별 세부 수치는 플레이테스트용 프리셋으로 분리해야 함 |
| 10 | 구간 길이/카메라/리스폰 프리셋 작성 | 5구간 구조는 확정됐지만 구간 길이, 카메라 속도, 리스폰 좌표는 수치 프리셋으로 내려야 함 |
| 11 | 문서 링크/경로 자동 검증 | 문서 이동 후 오래된 상대 경로가 남을 수 있으므로 공유 전후에 자동 검사 스크립트가 필요함 |
| 12 | 팀 공유본 리뷰 결과 반영 로그 | 팀원 검토 후 수정 의견을 기준문서, 세부설계, 백로그 중 어디에 반영했는지 추적해야 함 |
| 13 | Unity 구현 데이터와 문서 매핑표 | CardPool, BalanceProfile, SegmentProfile 같은 구현 데이터가 어느 문서를 따르는지 연결해야 함 |

## 다음 처리 방식

각 항목은 바로 구현하지 않는다. 협업 기준 문서가 `accepted` 상태가 된 뒤, 항목별로 다음 절차를 따른다.

1. 항목별로 문제와 목표를 1문장으로 고정한다.
2. `brief-gate`로 입력, 출력, 완료조건, 제약을 잠근다.
3. 기획 세션이 기준문서를 갱신한다.
4. 작업자는 갱신된 기준문서를 바탕으로 작업 브리핑를 받는다.

## 현재 결정

- 1차 기획마무리 범위에는 포함하지 않는다.
- 협업 기준이 잠긴 뒤 순차적으로 다룬다.
- 이 항목들을 이유로 현재 기준문서 확정을 지연하지 않는다.

## Post-MVP 카드 후보 (캐릭터 능력 계열, 2026-04-20 이관)

> 출처: `40_카드_무기_설계/10_세부설계/03_MVP_카드_후보_카탈로그.md` 보류 후보 섹션에서 이관.
> MVP 카드 범위는 총알/무기 효과만으로 확정(2026-04-20). 아래 항목은 MVP "총알 제어" 전제 검증 후 별도 트랙에서 평가한다.

| 후보 | 보류 이유 | 재평가 조건 |
|---|---|---|
| 점프 높이 상승 | 구간/카메라/경계 규칙과 TTK를 크게 흔든다 | 맵 구조·카메라 규칙 확정 후 |
| 2단점프 | 전장 압박과 구조물 대응법을 다시 설계해야 한다 | 구조물·경계 규칙 확정 후 |
| 대시 강화 | 기본 이동기로 둘지 특수 행동으로 둘지 먼저 결정해야 한다 | 입력/액션 기준 결정 후 |
| 리스폰 시간 감소 | 전투 카드가 아니라 라운드 흐름 카드에 가깝다 | 게임루프 보상 체계 확정 후 |
| 체력/방어 지속 성장 | 구간 돌파를 멈추는 방어 메타를 만들 위험이 있다 | TTK 안정화 + 플레이테스트 후 |
| 이동속도 변경 (캐릭터 능력) | 총알 제어 전제와 분리된 캐릭터 능력 카드 | 액션성 확장 트랙 개설 후 |
| 무기 교체 | MVP 핵심 차별점 아님 | MVP 총알 체계 검증 후 확장 검토 |
| 상태 이상탄 | 네트워크 truth, 누적, 가독성 부담이 크다 | 총알 확장 후보 트랙에서 별도 평가 |
| 레이저/즉발 공격 | 투사체 전제와 충돌하고 반응 가능성이 낮다 | MVP 제외 확정, 재평가 조건 없음 |
