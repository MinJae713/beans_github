# 미결정 질문 레지스터

이 문서는 여러 기준문서에 흩어진 미결정 질문을 한 곳에서 관리한다.

각 문서의 `미결정` 섹션은 현장 메모로 유지하고, 구현 판단을 막거나 여러 문서에 영향을 주는 질문은 이 레지스터에 등록한다.

## 사용 규칙

- 구현자가 멈춰야 하는 질문은 반드시 이 문서에 등록한다.
- 질문은 한 문장으로 적고, 영향 영역과 임시 가정을 함께 적는다.
- 답이 정해지면 관련 기준문서에 반영하고 이 문서에서는 `closed`로 바꾼다.
- 단순 아이디어나 언젠가 하고 싶은 기능은 이 문서가 아니라 백로그에 둔다.
- 정확한 수치값 논의는 이 문서가 아니라 BalanceProfile 또는 프리셋 실험 기록으로 보낸다.

## 상태값

| 상태 | 의미 |
|---|---|
| open | 결정이 필요하지만 아직 답이 없음 |
| assumed | 임시 가정으로 구현을 진행할 수 있음 |
| blocked | 답이 없으면 구현을 진행하면 안 됨 |
| closed | 결정이 기준문서 또는 구현 프리셋에 반영됨 |
| deferred | 지금 결정하지 않고 명시적으로 뒤로 미룸 |

## 결정 등급

| 등급 | 기준 |
|---|---|
| P0 | 구현 구조, 승패 규칙, 네트워크 truth, 공용 프리팹 소유권에 영향 |
| P1 | 특정 기능 품질이나 플레이테스트 해석에 영향 |
| P2 | 콘텐츠 확장, 문서 정리, 운영 편의에 영향 |

## 등급별 운영 트리거

| 조건 | 처리 |
|---|---|
| P0 open/blocked | 관련 구현 중단. 작업 브리핑에 BLOCKED 사유 기록 |
| P0 assumed | 구현 가능. 단, 브리핑에 임시 가정과 결정 필요 시점 명시 |
| P1 open | 현재 작업을 막지 않지만 해당 기능 구현 전 재검토 |
| P1 assumed/deferred | 플레이테스트, 리허설, 마일스톤 게이트에서 재확인 |
| P2 deferred | MVP 이후 백로그로 유지 |

## 팀 공유 기준 적용 전 분류

2026-04-20 기준 팀 공유 기준문서 적용 전 판정은 아래와 같다.

| 분류 | 해당 항목 | 처리 |
|---|---|---|
| P0 open/blocked | 없음 | 공유본 작성 가능 |
| P0 assumed | Q2, Q3 | 공유본에는 구현 주의사항으로 표시하고 관련 구현 브리핑에서 재확인 |
| P1 open | Q5 | 구조물/반사탄 구현 전 재확인 |
| P1 assumed | Q8, Q9, Q11, Q12, Q13, Q15, Q16, Q27, Q29, Q31 | 현재 구현을 막지 않지만 해당 기능 착수 전 가정 명시 |
| P1 deferred | Q4, Q6, Q21, Q28, Q37 | MVP 이후 또는 해당 기능 확장 전 재검토 |
| P2 open/deferred | Q17, Q22, Q32 | 공유본 말미의 보류/백로그로 표시 |

따라서 팀 공유본 작성 전 사용자에게 새로 물어야 하는 P0 질문은 없다. 다만 공유본은 `확정`, `임시 가정`, `보류`를 분리해서 작성해야 한다.

P0 `assumed` 질문은 아래 시점까지 다시 확인한다.

| id | 결정 필요 시점 | 확인 책임 |
|---|---|---|
| Q2 | 라운드 상태머신 구현 전 | 게임루프/네트워크 담당 |
| Q3 | 투사체 네트워크 구현 전 | 전투/네트워크 담당 |

## 닫힘 조건

질문을 `closed`로 바꿀 때는 아래 중 하나 이상이 있어야 한다.

- 관련 기준문서가 갱신됨.
- 구현 프리셋 또는 테스트 기준으로 반영됨.
- 팀/기획/구현 합의가 남아 있음.
- 해당 질문이 더 이상 유효하지 않다는 폐기 근거가 남아 있음.

## 상세 미결정 메모

### Q22 — 팀전 2v2 포함 여부 및 1v1 상태머신 확장 범위

- 상태: `deferred`
- 등급: `P2`
- 임시 가정: MVP는 1v1로 고정한다.
- 평가 시점: 1v1 MVP 안정화와 1차 시연 이후.
- 배경: 프로젝트 비전과 라운드 상태머신은 현재 1v1 전제를 따른다.
- 재검토 하위 질문:
  - 2v2에서 구간 돌파자는 누구로 정의하는가?
  - 동시 사망 또는 한 팀 일부 사망 시 카드 지급 주체는 누구인가?
  - 카드 선택권은 한 명에게만 주는가, 팀 전체에게 주는가?
  - 리스폰 위치와 카메라 압박 기준은 팀 단위로 어떻게 바뀌는가?
  - 팀전에서 관전/매칭/부하 기준이 얼마나 증가하는가?
- 닫힘 조건: 1v1 상태머신과 카드 지급 규칙이 안정된 뒤 별도 2v2 평가 문서를 만든다.

## 운영 기준

- P0 `blocked` 질문이 있으면 관련 구현은 중단한다.
- P0 `assumed` 질문은 임시 가정이 작업 브리핑에 명시되어야 한다.
- P1/P2 질문은 현재 작업을 막지 않되, 플레이테스트나 기능 확장 전에 재검토한다.
- 같은 질문이 반복되면 개별 문서에 흩어두지 않고 이 문서의 ID를 참조한다.
