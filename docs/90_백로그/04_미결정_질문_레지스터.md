# 미결정 질문 레지스터

이 문서는 여러 기준문서에 흩어진 미결정 질문을 한 곳에서 관리한다.

각 문서의 `미결정` 섹션은 현장 메모로 유지하고, 구현 판단을 막거나 여러 문서에 영향을 주는 질문은 이 레지스터에 등록한다.

## 사용 규칙

- 구현자가 멈춰야 하는 질문은 반드시 이 문서에 등록한다.
- 질문은 한 문장으로 적고, 영향 영역과 임시 가정을 함께 적는다.
- 답이 정해지면 관련 기준문서에 반영하고 이 문서에서는 `closed`로 바꾼다.
- 단순 아이디어나 언젠가 하고 싶은 기능은 이 문서가 아니라 백로그에 둔다.
- 정확한 수치값 논의는 이 문서가 아니라 GameplayProfile 또는 프리셋 실험 기록으로 보낸다.

## 상태값

| 상태 | 의미 |
|---|---|
| open | 결정이 필요하지만 아직 답이 없음 |
| assumed | 임시 가정으로 구현을 진행할 수 있음 |
| blocked | 답이 없으면 구현을 진행하면 안 됨 |
| closed | 결정이 기준문서 또는 구현 프리셋에 반영됨 |
| deferred | 지금 결정하지 않고 명시적으로 뒤로 미룸 |

## 결정 등급

| 등급 | 기준 |
|---|---|
| P0 | 구현 구조, 승패 규칙, 네트워크 truth, 공용 프리팹 소유권에 영향 |
| P1 | 특정 기능 품질이나 플레이테스트 해석에 영향 |
| P2 | 콘텐츠 확장, 문서 정리, 운영 편의에 영향 |
