# QA 로그

> 상태: reference. 2026-04-21 T2 회의 결정에 따라 생성.
>
> 스모크·플레이테스트·원격 부하 리허설·Gate 검증 등 **QA 실행 결과를 회차별로 누적 기록**한다.

## 목적

- `70_검증_체크리스트/`는 QA **양식·기준**을 정의 → 정본
- 본 폴더는 QA **실제 실행 결과**를 누적 기록 → 로그
- 회차별 실행 결과를 모아 플레이테스트 추이, 회귀 버그, 성능 변화를 추적

## 기록 대상

| 유형 | 양식 출처 | 파일 네이밍 |
|---|---|---|
| 스모크 리허설 결과 | `70/01_스모크테스트.md` | `YYYY-MM-DD_smoke_{n회차}.md` |
| Fusion 로컬 2P 리허설 | `70/05_Fusion_로컬_2인_리허설.md` | `YYYY-MM-DD_local2p_{n회차}.md` |
| 첫 Playable Slice 검증 | `70/06_첫_Playable_Slice_검증_패킷.md` | `YYYY-MM-DD_slice_{n회차}.md` |
| 네트워크 부하 리허설 | `70/07_네트워크_부하_리허설.md` | `YYYY-MM-DD_netload_{n회차}.md` |
| Gate 통과 플레이테스트 | `70/04_마일스톤_게이트.md` + `70/02_플레이테스트_리포트_양식.md` | `YYYY-MM-DD_gateN_playtest.md` |
| 버그 관찰 기록 | 자유 양식 | `YYYY-MM-DD_bug_{slug}.md` |

## 기록 원칙

- **회차별 독립 파일**. 한 파일에 여러 회차 누적 금지 → 비교 어렵고 머지 충돌.
- **인접 QA에서 발견된 회귀**는 이전 로그 URL 참조.
- **Gate 통과 여부는 본 로그 + `05/06` D-번호에 함께 등록**.
- **치명 버그(crash/desync/progression lock)** 발견 시 Jira 이슈 생성하고 이슈 키 본 로그에 역참조.
