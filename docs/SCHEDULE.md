## AI 세션의 스코프 판단 기준

팀원의 AI가 작업 범위를 판단할 때 아래를 따른다.

| 판단 상황 | 기준 |
|---|---|
| "이 피처를 이번 주에 넣을까?" | 현재 주차의 주차 목표에 포함되어야 진행. 아니면 다음 주차 백로그. |
| "이 리팩토링을 지금 할까?" | W1~W2는 리팩토링보다 구현 우선. W4는 리팩토링 금지, 안정화만. |
| "이 개선이 MVP에 들어갈까?" | G4 Pass 기준에 필요한가. 아니면 MVP 외 백로그로 이동. |
| D-day 주간 작업 | 치명 버그 수정만. 새 기능 금지. |
