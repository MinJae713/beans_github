# Jira Git 컨벤션

이 디렉토리는 팀의 Jira, Git, MR, Unity 협업 규칙을 모은다.

게임 규칙과 기술 구조만 맞아도 협업 운영이 흔들리면 Unity 프로젝트는 쉽게 충돌한다. 특히 씬, 프리팹, meta 파일, NetworkObject, Photon 설정은 한 번 꼬이면 원인 추적 비용이 크다.

## 문서 목록

| 문서 | 목적 |
|---|---|
| `01_Jira_Git_컨벤션.md` | Jira 구분자, 브랜치, 커밋, MR, Unity/문서 특화 운영 규칙 |

## 적용 원칙

- Jira 이슈는 가능한 한 하나의 DRI를 가진다.
- 브랜치와 커밋은 Jira 이슈 키를 연결한다.
- MR에는 테스트 방법, 변경한 씬/프리팹, NetworkObject 변경 여부를 적는다.
- 기준문서 변경은 `docs/` 브랜치에서 작업하고 MR로 검토한다.
- Photon App ID, secret, 계정 정보는 문서, MR 본문, tracked 설정 파일에 실제 값으로 직접 적지 않는다.
- 실제 GitLab protected branch 설정이 문서와 다르면 담당자 확인 후 문서를 갱신한다.
