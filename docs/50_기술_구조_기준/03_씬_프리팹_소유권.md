# 씬 프리팹 소유권

이 문서는 Unity 협업에서 씬, 프리팹, ScriptableObject 충돌을 줄이기 위한 소유권 기준을 정의한다.

개인 로컬 절대경로, 팀원 개인 PC 경로, 임시 작업 디렉토리는 이 문서에 적지 않는다.

## 기본 원칙

- 씬과 공용 프리팹은 동시 수정 금지 대상으로 본다.
- 한 작업 브리핑는 수정 가능, 읽기 전용, 동시 수정 금지, 생성 가능 위치를 명시해야 한다.
- 테스트용 임시 씬과 샌드박스 프리팹은 공용 씬/프리팹과 분리한다.
- 큰 프리팹 하나에 모든 기능을 몰아넣지 않고, 역할별 하위 프리팹과 데이터 프리셋으로 나눈다.
- 충돌 가능성이 있으면 구현을 시작하기 전에 미결정 질문 레지스터에 등록한다.

## 소유권 범주

| 범주 | 의미 |
|---|---|
| 수정 가능 | 이번 작업자가 실제 변경해도 되는 파일/디렉토리 |
| 읽기 전용 | 참고 가능하지만 수정하면 안 되는 파일/디렉토리 |
| 동시 수정 금지 | 한 번에 한 작업자만 수정해야 하는 씬/프리팹/SO |
| 생성 가능 | 새 테스트, 새 프리팹, 새 프리셋, 새 산출물을 만들 수 있는 위치 |

## 동시 수정 금지 대상

| 대상 | 이유 |
|---|---|
| 메인 플레이 씬 | serialize 충돌과 merge 난도가 큼 |
| 공용 플레이어 프리팹 | 입력, 물리, 네트워크, 애니메이션 의존성이 집중됨 |
| 공용 무기/투사체 프리팹 | 판정과 VFX가 함께 엮일 위험 |
| 공용 HUD 프리팹 | 카드 선택, 체력, 탄약 표시 충돌 가능 |
| 공용 GameplayProfile | 수치 실험 충돌과 원인 추적 어려움 |
| 공용 NetworkRunner 설정 | Photon/Fusion 런타임 설정 충돌 가능 |

동시 수정 금지 대상은 수정 자체가 금지된다는 뜻이 아니다. 같은 시간대에 여러 작업자가 같은 대상을 수정하지 않도록 작업 브리핑에서 소유자를 잠그라는 뜻이다.

## 생성 가능 위치 기준

| 산출물 | 기준 |
|---|---|
| 기능별 스크립트 | 역할 레이어에 맞는 Runtime 하위 경로 |
| 테스트 코드 | EditMode/PlayMode 테스트 하위 경로 |
| 임시 실험 씬 | 공용 씬과 분리된 sandbox 또는 test scene 경로 |
| 프리셋 후보 | Config 또는 Presets 하위 경로 |
| raw 로그/스크린샷 | 팀이 합의한 레포 밖 또는 ignore된 로컬 artifact 경로 |
| 문서 요약 | `docs/` 또는 관련 `docs/` 경로 |

정확한 Unity 폴더명은 구현 레포의 실제 구조를 따른다. 이 문서는 개인 PC 기준 경로가 아니라 역할 기준을 정의한다.

## 작업 브리핑에 포함할 항목

| 항목 | 작성 기준 |
|---|---|
| 수정 가능 | 실제 변경할 파일/폴더 |
| 읽기 전용 | 참고만 할 파일/폴더 |
| 동시 수정 금지 | 소유권 잠금이 필요한 씬/프리팹/SO |
| 생성 가능 | 새 파일을 만들 수 있는 위치 |
| 충돌 시 처리 | 중단, 레지스터 등록, 작업 분리 중 하나 |

## 레이어별 소유권 기준

- Domain 작업은 씬과 프리팹을 직접 수정하지 않는 방향을 우선한다.
- Presentation 작업은 씬/프리팹을 수정할 수 있으므로 소유권 잠금이 필요하다.
- 현재 구현처럼 `Scripts/Presentation/**`와 `Scripts/NetworkGameplay/**`가 분리된 경우에도, 같은 씬/프리팹 안에 두 레이어 컴포넌트가 공존할 수 있다. 이때 씬/프리팹 잠금은 코드 레이어가 아니라 **실제 YAML 수정 대상** 기준으로 판단한다.
- Input 작업은 `INetworkInput`, Input Actions, 키 매핑 프리셋의 범위를 명시한다.
- Config 작업은 ScriptableObject와 프리셋 파일을 직접 건드리므로 변경 이유와 되돌림 기준을 남긴다.
- Network 작업은 `NetworkObject`, `NetworkBehaviour`, `NetworkRunner` 설정 충돌을 우선 검토한다.

## 금지

- 작업 브리핑 없이 공용 씬 또는 공용 플레이어 프리팹을 수정하는 것.
- 테스트용 임시 오브젝트를 메인 씬에 남기는 것.
- 개인 로컬 절대경로를 기준문서나 팀 공유 대상 문서에 적는 것.
- GameplayProfile 수치 실험을 이유 없이 공용 기본 프리셋에 직접 덮어쓰는 것.
- 3D 물리 기반 컴포넌트를 새 공용 프리팹에 추가하는 것.

## 미결정

- 실제 Unity 프로젝트의 최종 폴더 구조에 맞춘 생성 가능 경로명.
- 공용 메인 씬을 하나로 둘지, 기능별 additive scene으로 나눌지.
- GameplayProfile 실험본의 명명 규칙과 폐기 기준.
