## 왜 이 문서가 필요한가

W3에 로비/매칭을 구현해야 하는데 기준문서가 없었다. 담당자마다 다른 매칭 방식을 구현하면 W3 Exit ② "첫 원격 2P 매치 성공"과 W3 ③ 첫 Playable Slice 검증에 desync/UX drift가 생긴다. 이 문서는 MVP 매칭·로비의 공통 기준을 정의한다.

## 범위와 비범위

### 범위

- Fusion 세션 생성·입장 방식
- 방 관리 (방 코드, 공개 방, 비공개 방)
- 연결 실패·재연결 정책 (MVP 최소)
- 로비 화면의 최소 기능

### 비범위

- 스킬 기반 매치메이킹 (MVP 제외)
- 랭크 시스템·리더보드 (2차 릴리스)
- 관전 기능 (`90/04 Q21` deferred)
- 방 친구 초대·Discord Rich Presence (2차)

## Fusion 세션 모드 3안 비교

| 옵션 | 방식 | 장점 | 단점 | MVP 적합도 |
|---|---|---|---|---|
| A. Host Mode + Room Code | 방장이 세션 생성, 6자리 코드 공유로 입장 | 구현 단순, 시연 제어 용이, 비공개 기본 | 공개 방 검색 불가 | ★★★★★ |
| B. Public Room (Lobby Browser) | 공개 방 목록에서 선택 입장 | UX 친숙 | 빈 방/유령 방 UX 처리 부담 | ★★ |
| C. Auto-Match | 대기열 → 서버가 짝 매칭 | 완전 자동 | 상태 머신 복잡, 5인 테스트 규모 과함 | ★ |

## MVP 권장 — Option A (Host + Room Code)

### 기본 흐름

1. **방장**: 로비에서 "방 만들기" → Fusion `StartGame(GameMode.Host)` → 6자리 방 코드 생성 → 화면 표시.
2. **참가자**: "방 코드 입력" → Fusion `StartGame(GameMode.Client)` (`SessionName = 방 코드`) → 방 입장.
3. **방장이 "시작"** → 모든 참가자 로드 확인 → 매치 시작.

### 방 코드 규칙

- 6자리, 영문 대문자 + 숫자, 혼동 문자(`0/O`, `1/I/L`) 제외.
- `StartGameArgs.SessionName`으로 사용.
- 매치 종료 시 세션과 함께 자동 폐기.

### 공개 방(Option B)는 2차 후보

시연 후 필요 시 lobby browser 추가. MVP는 비공개 기본.

## 네트워크 truth 표 로비 state (`50/02`에 추가 예정)

| 상태 | Authority | 표현 | 전이 조건 |
|---|---|---|---|
| `Lobby.Empty` | Local | 로비 메인 화면 | 초기 진입 / 매치 종료 후 복귀 |
| `Lobby.Creating` | InputAuthority → StateAuthority | "방 생성 중" 스피너 | "방 만들기" 클릭 |
| `Lobby.Joining` | InputAuthority → StateAuthority | "입장 중" 스피너 | 방 코드 입력 후 확인 |
| `Lobby.InRoom` | Networked | 방 코드·참가자 목록 표시 | 세션 입장 성공 |
| `Lobby.Starting` | StateAuthority | 매치 시작 카운트다운 | 방장 "시작" 클릭 |

## 연결 실패·재연결 정책 (MVP)

- **연결 실패**: 에러 메시지 + 로비로 복귀. 자동 재시도 없음.
- **세션 중 끊김**: 현재 매치 중단 + 로비 복귀. 재접속은 2차 후보.
- **타임아웃**: Fusion 기본값 사용.

## 금지선

- 방 비밀번호·개인 계정 ID·이메일·Discord 핸들을 방 코드 또는 세션 이름에 포함하지 않는다.
- Photon Cloud AppID는 이 문서 또는 본 레포에 직접 기록하지 않는다 (`04_Fusion_구현_가드레일.md` 금지선 계승).
- 방 코드를 영구 저장하지 않는다 (세션 종료 시 즉시 폐기).
- 참가자 목록에 플레이어 개인 식별 정보를 노출하지 않는다.

## 검증 기준 (W3 Exit 시)

- **로컬 2P**: 방 생성 → 코드 공유 → 입장 → 매치 시작 → 종료까지 1회 완주.
- **원격 2P**: 동일 흐름을 Photon Cloud KR 리전에서 1회 완주.
- **잘못된 방 코드**: 에러 메시지 표시 후 로비 유지, 앱 유지.
- **동시 입장**: 방장 포함 2명이 같은 방에 동시 입장 성공.
