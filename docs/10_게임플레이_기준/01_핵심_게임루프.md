# 핵심 게임루프

> 상태: accepted_candidate. 이 문서는 1v1 MVP, 구간 돌파 중심, 구간 돌파 패배 카드 지급, 최종 승리 흐름에 한해 임시 구현 기준으로 사용한다. 문서 상태와 binding 범위는 `05_문서관리_규칙/08_문서_상태_인덱스.md`를 우선한다.

## 용어

| 용어 | 의미 |
|---|---|
| 전장 | 여러 구간이 이어진 전체 맵 |
| 구간 | 한 번의 라운드가 벌어지는 개별 맵 단위 |
| 구간 돌파 | 공격자가 현재 구간의 상대 방향 끝을 넘어 다음 구간으로 미는 것 |
| 전투 구간 | 실제 교전, 사망, 구간 돌파, 구간 돌파 패배 카드 보상이 발생하는 가운데 구간 |
| 최종 구간 | 매치 승리를 확정하기 위한 양끝 구간. 상대는 리스폰하지 않고 승리 예정 캐릭터만 진행 |
| 이동 주도권 | 직전 전투 결과로 전진 방향을 얻은 플레이어의 권한. 주도권 보유자는 뒤로 이동할 수 없음 |
| 매치 승리 | 상대 최종 진영 끝에 도달한 뒤 조작 불가능한 최종 연출이 시작되는 것 |

## 기본 루프

```text
전투 구간 시작
-> 위치 싸움과 교전
-> 일반 사망 또는 구간 돌파
-> 일반 사망이면 이동 주도권 이전 후 재교전
-> 전투 구간 돌파 패배이면 방어자 카드 선택
-> 다음 전투 구간으로 전선 이동
-> 최종 구간 진입
-> 승리 예정 캐릭터가 끝 지점까지 이동
-> 최종 연출 후 매치 종료
```

## 승패 규칙

| 상황 | 처리 |
|---|---|
| 상대 체력 소진 | 일반 사망 처리. MVP 기준으로 즉시 카드 지급하지 않고 킬러에게 이동 주도권 부여 |
| 전투 구간에서 이동 주도권 보유자의 공격 방향 구간 돌파 | 돌파자 구간 승리, 방어자 패배 처리, 방어자 카드 선택. 돌파 판정 주체는 `SegmentBoundary` 콜라이더의 `OnTriggerEnter` (Q40 D44, [30/01 §구간 돌파 판정 방식](../30_전장_레벨디자인/01_전장_구간_기준.md) 참조) |
| 이동 주도권이 없는 플레이어의 **자발적** 후방 이탈 | 낙사/경계 패배로 처리. MVP 임시 기준으로 일반 사망과 동일하게 즉시 카드 선택권을 주지 않음. 단, **넉백에 의한** 경계 이탈은 Q41 D45로 무효화되어 clamp 처리([10/02 §결과 판정](02_라운드_상태머신.md) 참조) |
| 최종 구간 진입 | 패배자 리스폰 없이 승리 예정 캐릭터만 등장 |
| 최종 구간 끝 도달 | 조작 불가능한 최종 연출 시작, 매치 최종 승리 확정 |

구간 돌파를 당한 방어자는 사망과 동일한 패배 결과로 취급한다. 단, MVP 기준 카드 지급은 모든 사망이 아니라 구간 돌파 패배를 기본 트리거로 한다.

## 전장/구간 수 기준

- MVP 기준 전장은 5개 구간으로 설계한다.
- 가운데 3개 구간은 전투 구간이다.
- 양끝 2개 구간은 최종 승리를 위한 playable 컷신/승리 예정 구간이다.
- 최종 구간에 진입하면 상대방은 리스폰하지 않는다.
- 최종 구간에서는 승리 예정 캐릭터가 끝 지점까지 달려가며 승리감을 확인한다.
- 최종 승리는 최종 구간 진입 순간이 아니라, 끝 지점에 도달해 조작 불가능한 연출이 시작될 때 확정한다.
- 전투 구간은 카메라 viewport보다 넓게 설계해 전선 압박과 화면 밖 압박을 만든다.
- 최종 구간은 전투 구간보다 짧고 읽기 쉬워야 하며, 승리 연출을 위한 달리기 시간이 있어야 한다.
- 테스트 구현에서 임시로 더 많은 구간을 만들 수는 있지만, 기준 기획은 5개 구간 구조를 우선한다.

## 카드 지급 기준

- 카드는 패배자를 밀어주기 위한 장치이지, 매번 무제한으로 누적되는 보상이 아니다.
- MVP 기준 카드 지급 트리거는 구간 돌파 패배다.
- 일반 사망마다 카드를 지급하지 않는다.
- 상대가 만든 일반 전투 사망에 카드를 줄지는 보류한다. 카드 수령 횟수 제한과 함께 재검토한다.
- 카드 보유 수는 티어별 제한을 둔다.
- 정확한 티어별 보유 수는 기준문서가 아니라 카드 프리셋 또는 BalanceProfile에서 관리한다.
- 카드 지급이 강한 카드를 일부러 받기 위한 고의 패배 전략을 만들면 안 된다.

## 리스폰 기준

- 리스폰은 구간 절대 중앙이 아니라 카메라 기준으로 재정렬한다.
- 공격자와 방어자는 서로 대칭되는 위치에서 재개한다.
- 공격자는 공격 방향을 유지하되 즉시 구간 끝에 닿지 않아야 한다.
- 방어자는 압박을 받는 상태에서 시작하되 리스폰 직후 즉시 피격되지 않아야 한다.
- 정확한 리스폰 비율은 `BalanceProfile` 또는 레벨 프리셋에서 관리한다.

## 자원 유지 기준

| 대상 | 처리 |
|---|---|
| 돌파자 | 체력, 탄창, 쿨타임 등 전투 자원을 가능한 유지 |
| 사망/방어자 | 사망 처리이므로 리스폰 기준 자원으로 초기화 |
| 카메라 이탈 패배 | MVP 임시 기준으로 일반 사망과 동일하게 즉시 카드 선택권을 주지 않음 |

돌파자까지 모든 자원을 리셋하면 공격 성공의 리스크를 보상해주는 결과가 될 수 있으므로, 돌파자는 자원을 유지하는 방향을 기본으로 한다.

## 전투 템포 기준

- 목표 TTK는 짧은 즉사전보다 긴 교전과 위치 싸움을 우선한다.
- **초기 상태(카드 0장) 기본 무기는 한 탄창만으로 풀피 대상을 죽일 수 없어야 한다.** 카드 누적 성장 이후 TTK 단축은 허용되며 ROUNDS식 "성장 뽕맛"이 의도다(Q43 D47 Option A, [20/01 밸런스 철학](../20_전투_밸런스_기준/01_밸런스_철학.md) 정본 참조).
- 전투는 체력 기반 킬각보다 위치 기반 킬각이 우선되어야 한다.

## 킬각 우선순위

| 순위 | 킬각 |
|---|---|
| 1 | 위치 기반 킬각 |
| 2 | 쿨타임/점프 소모 기반 킬각 |
| 3 | 체력 기반 킬각 |

## 압박 우선순위

| 순위 | 압박 방식 |
|---|---|
| 1 | 벽 몰이/구석 압박 |
| 2 | 카메라/화면 밖 압박 |
| 3 | 고저차 압박 |
| 4 | 낙사/위험 지형 |

## 보류/프리셋 항목

- 카메라 이탈 패배는 MVP 기준 일반 사망과 동일하게 즉시 카드 지급하지 않는다. 이후 별도 보정이 필요한지는 플레이테스트 후 판단한다.
- 상대가 만든 일반 전투 사망에 제한적으로 카드 지급을 줄지는 MVP 이후 보류한다.
- 구간별 위험 지형의 허용 강도는 레벨 프리셋과 플레이테스트 기록에서 조정한다.
- 카드 선택 제한 시간의 정확한 값은 기준문서가 아니라 프리셋 또는 UI 정책에서 관리한다.
