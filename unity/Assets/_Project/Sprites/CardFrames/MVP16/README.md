# MVP16 Card Frame Sprites

This folder stores the four MVP card exterior frame sprites used by `CardSelectionUI`.

- `card_frame_common.png`
- `card_frame_rare.png`
- `card_frame_epic.png`
- `card_frame_legendary.png`

The frame sprites are the outer card exterior layer. Card-specific `CardData.cardIcon` references remain the inner illustration layer and do not define gameplay truth or balance values.
